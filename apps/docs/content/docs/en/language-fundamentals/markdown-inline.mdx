## Markdown Paragraphs

Body text that is outside structured blocks becomes a `MarkdownNode`. The node preserves its original `value` and carries `references`, `inlineChem`, `inlineCode`, and `links`.

```md
The reaction mixture stayed homogeneous for 30 min.
TLC showed full consumption of @mol-substrate.
```

## `@id` Object References

`@mol-main` produces a reference token with `kind: "object"`. The resolver looks up the source ID in the object index. Missing targets produce `W_UNRESOLVED_REFERENCE`.

```md
The limiting reagent was @mol-substrate.
```

## `@id.field` Field References

`@res-main.yield` produces `kind: "object_field"`. The resolver first locates the object and then reads the requested field. For `condition_varies`, the field reader can also return an attempt by ID.

```md
Isolated yield: @res-main.yield.
Attempt summary: @cv-screen.var1.
```

## Primary Aliases such as `@reaction.field`

`reaction`, `result`, `product`, `sample`, `molecule`, and `analysis` are primary alias names. `@reaction.name` resolves through `primary_reaction` and then reads `name` from the target object.

```md
Primary reaction: @reaction.name.
Primary result yield: @result.yield.
```

## `@meta.field` Metadata References

`@meta.title` reads `title` from frontmatter. Missing fields produce unresolved-reference diagnostics.

```md
Record title: @meta.title.
Campaign: @meta.campaign.
```

## `@param.field` Template Parameter References

`@param.temperature` reads the value supplied by `:::use` in a template expansion context. Names declared in template `bind` are resolved as aliases and are not exposed through `@param`.

```md
:::template heat-note
params: temperature: quantity<temperature> | duration: quantity<time>
Heating was held at @param.temperature for @param.duration.
:::

:::use heat-note
temperature: 65 C
duration: 4 h
:::
```

## `:chem[...]` Inline Chemistry

`:chem[CCO]` produces an `InlineChemToken`. Empty values, multiline content, and missing closing brackets do not produce tokens.

```md
The solvent was :chem[CCO], and the product SMILES was :chem[COc1ccc(-c2ccccc2)cc1].
```

Inline code uses backticks and produces `InlineCodeToken`. Empty code spans and multiline code spans are ignored by the tokenizer.

```md
Use `kind: reaction` when the block contains `reactants` or `products`.
```

## Markdown Link Safety

Markdown link tokens include `safe`. Safe href values include anchors, absolute paths, relative paths, scheme-free text, `http`, `https`, and `mailto`. Control characters and unsupported schemes produce `W_UNSAFE_LINK_HREF`.

```md
[local method](./methods/suzuki.md)
[instrument record](https://example.test/instruments/hplc-01)
[unsafe](javascript:alert(1))
```

## Inline Syntax Implementation Inventory

Reference tokens require IDs that start with a letter and continue with letters, digits, underscores, or hyphens. Field names use the same character family. This lets prose references address structured block IDs and AST fields.

Primary aliases cover only `reaction`, `result`, `product`, `sample`, `molecule`, and `analysis`. These names are resolved as aliases first. Ordinary objects should use explicit IDs when their names could collide with an alias.

The Markdown link tokenizer supports href values with nested parentheses. Safety validation runs during parsing, so renderers can consume the `safe` flag directly. Unsafe links retain their original label and href for editor diagnostics.
