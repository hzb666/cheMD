## `:::result`

`:::result` produces a `ResultNode`. The resolver currently has no general required-field rule for result nodes. High-quality records usually include an ID, an association field, and at least one result metric.

## `ref`, `reaction`, and `product`

`ref`, `reaction`, and `product` are stored as string fields. In the current typechecker, `reaction` takes priority and `ref` is used as the fallback reaction reference. `product` points to a product molecule.

## `yield`, `conversion`, `selectivity`, and `purity`

These fields preserve the authored text in the AST, then the typechecker parses them as percent quantities. Percent-sign values are compact literals, for example `82%`; spaced forms such as `82 %` are errors.

## `:::analysis`

`:::analysis` produces an `AnalysisNode`. The source field `type` maps to AST field `type_name`.

```md
:::analysis #ana-hplc-main
type: hplc
ref: @res-main
method: HPLC area normalization
instrument: Agilent 1260
peak: 6.4 min (97%, product)
data: Main peak at 6.4 min with trace impurity.
:::
```

## TLC Lanes

TLC uses explicit `lane:` sections. A lane can contain `spot:`, `mess:`, `base:`, or `none`. A one-token `spot:` such as `spot: sm` references a known spot from another lane; unresolved or conflicting references are errors.

## Generic NMR and HPLC Analysis

NMR records use `spectrum:` plus `peak:` lines. HPLC, UPLC, and GC use `peak:` lines. LCMS and GCMS use both `peak:` and `ion:` lines.

## Required Analysis Fields and TLC Defaults

Analysis requires `type_name`. TLC records receive default `plate: silica gel GF254` and `visualization: UV 254 nm` when those fields are absent.

## Result Typecheck Inventory

The typechecker normalizes result `status` to success, partial, failed, or unknown; parses `yield`, `conversion`, `selectivity`, and `purity` as percent quantities; parses `isolated_mass` as a mass quantity; resolves `reaction` or fallback `ref` as a reaction reference; and resolves `product` as a molecule reference.

Linked result validation has two checks. `product` must appear in the linked reaction products. Result `yield`, `conversion`, and `selectivity` are compared against the same fields on the linked reaction, with mismatches producing `E_RESULT_REACTION_CONFLICT`.

## Analysis Typecheck Inventory

The analysis `type` field is stored as `type_name` in the AST. The typechecker recognizes `tlc`, `nmr`, `hplc`, `uplc`, `gc`, `lcms`, `lc-ms`, `gcms`, `gc-ms`, `ms`, `hrms`, `ir`, `uv`, and `uv-vis` through `normalizeAnalysisType`. Unmatched values are retained as extensions.

TLC analysis is classified through `classifyTlcAnalysis`. `lane:`, `spot:`, `mess:`, `base:`, and `none` participate with `eluent`, `plate`, and `visualization` in normalized TLC output.

## Best Practice Example

Connect the result to the reaction and product, then connect analyses to the result or sample. Use TLC defaults only when they match the actual plate and visualization method.

```md
:::result #res-main
reaction: @rxn-main
product: @mol-product
status: success
yield: 82%
isolated_mass: 120 mg
purity: 98%
notes: isolated after silica gel chromatography
:::

:::analysis #ana-tlc-main
type: tlc
ref: @res-main
eluent: petroleum ether/ethyl acetate 5:1
plate: silica gel GF254
visualization: UV 254 nm
lane: sm
spot: 0.62
lane: rxn
spot: sm
spot: 0.31 ^3(4) prod
lane: prod
spot: 0.31
result: product spot observed, starting material consumed
:::

:::analysis #ana-nmr-product
type: nmr
ref: @sample-product
spectrum: 1H NMR (400 MHz, CDCl3)
peak: 7.68-7.59 (m, 2H, ArCH)
peak: 7.14-7.03 (m, 2H, ArCH)
peak: 3.56 (tt, J = 9.1, 6.0 Hz, 1H, CH(C=O))
artifact: @art-nmr-1h
:::

:::analysis #ana-hplc-product
type: hplc
ref: @res-main
instrument: Agilent 1260
method: C18 gradient
peak: 6.4 min (98%, product)
:::

:::analysis #ana-lcms-product
type: lcms
ref: @sample-product
method: ESI positive
peak: 6.4 min (98%, product)
ion: m/z 321.1234 [M+H]+
:::
```
