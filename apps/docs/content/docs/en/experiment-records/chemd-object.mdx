## `kind: molecule`

`kind: molecule` produces a `MoleculeNode`. A molecule is chemical identity: structure, names, identifiers, formula, and molecular weight. Reaction usage quantities do not belong on molecule nodes; write amount and equivalents on reaction participants.

```md
:::chemd #mol-aryl
kind: molecule
name: aryl bromide
smiles: Brc1ccccc1
role: substrate
formula: C6H5Br
:::
```

Field reference:

| field | semantics |
| --- | --- |
| `smiles` | structure expression |
| `cas` | CAS registry string, stored as raw text |
| `inchi` | InChI identifier |
| `inchikey` | InChIKey identifier |
| `canonical_smiles` | canonical structure string |
| `name` | user-facing name |
| `role` | user-defined role such as substrate, reagent, or product |
| `caption` | render-layer caption |
| `formula` | molecular formula text |
| `mw` | molecular weight text |
| `chemistry_features` | extension feature reference list |

## `kind: reaction`

`kind: reaction` produces a `ReactionNode`. Use repeated `reactant` and `product` fields for the canonical form. `reac` and `prod` are aliases. `reactants` and `products` remain simple list aliases, but structured quantities are only valid on singular participant fields.

```md
:::chemd #rxn-main
kind: reaction
name: Suzuki coupling
reactant: @mat-aryl-lot-a | 1.00 mmol | 1.0 eq | limiting=true
reactant: @mol-boron | 1.5 eq
product: @mol-product
reagents: K2CO3
catalyst: Pd(PPh3)4
solvent: dioxane/water
temperature: 90 C
time: 12 h
atmosphere: nitrogen
yield: 82 %
:::
```

The typechecker resolves reaction participants against molecule, material, or batch nodes; validates limiting-reactant boundaries; resolves `prev` route references; parses `temperature`, `time`, and `pressure`; and normalizes `atmosphere`.

## Type Inference When `kind` Is Omitted

The parser infers the `chemd` block type from field shape. Participant fields infer reaction; identity fields such as `smiles`, `cas`, `inchi`, `inchikey`, `canonical_smiles`, `formula`, or `mw` infer molecule. Unstable inference emits a `W_CHEMD_KIND_AMBIGUOUS` error with quick fixes for inserting `kind: molecule` or `kind: reaction`.

Conflict matrix:

| input shape | diagnostic |
| --- | --- |
| `kind: molecule` with reaction-shaped fields | `E_CHEMD_KIND_CONFLICT` |
| `kind: reaction` without reaction-shaped fields | `E_CHEMD_KIND_CONFLICT` |
| empty or invalid `kind` | `E_CHEMD_KIND_CONFLICT` |
| omitted `kind` with no stable field-shape inference | `W_CHEMD_KIND_AMBIGUOUS` |

## Molecule Field Reference

Molecule fields are limited by the schema registry. Unknown fields produce `W_UNKNOWN_FIELD` and are omitted from the AST. Non-field body content can be read as an implicit `smiles` value; multiple implicit lines produce `W_INVALID_CHEMD_IMPLICIT_VALUE`.

Molecule identity is required by the typechecker. A molecule with no identity field emits `E_MOLECULE_IDENTITY_MISSING`. `amount` or `equivalents` on a molecule emits `E_MOLECULE_REACTION_QUANTITY`.

## Reaction Field Reference

Reaction fields are limited by the schema registry. Repeated singular participant fields are canonical; list aliases are retained for simple lists.

| field | parsing and semantics |
| --- | --- |
| `reactant` / `reac` | repeatable reactant participant; supports reference, amount, equiv, mass, volume, and `limiting=true` |
| `product` / `prod` | repeatable product participant |
| `reactants` | simple reactant reference/literal list alias |
| `products` | simple product reference/literal list alias |
| `conditions` | string list used by rendering and export |
| `route` | route label |
| `prev` | predecessor reaction reference list |
| `reagents` | raw text |
| `catalyst` | raw text |
| `solvent` | raw text and input to condition classification |
| `temperature` | temperature quantity |
| `time` | time quantity |
| `pressure` | pressure quantity |
| `atmosphere` | `nitrogen`, `argon`, `air`, `oxygen`, `inert`, or extension |
| `yield` | AST string compared against linked result yield |
| `conversion` | AST string compared against linked result conversion |
| `selectivity` | AST string compared against linked result selectivity |

## Participant References

`reactant` and `product` values start with a reference or literal. References can use `@id` or bare IDs. The typechecker treats a bare ID as a reference when it resolves locally or through the external target index; unresolved bare values remain literals.

```md
reactant: @mat-aryl-lot-a | 1.00 mmol | 1.0 eq | limiting=true
reactant: mol-boron | 1.5 eq
product: @mol-product
```

Invalid list example:

```md
reactants: @mol-a | 1.0 mmol
```

Structured participant facts on plural list aliases produce `E_REACTION_PARTICIPANT_SYNTAX`. A trailing separator creates an empty list item and produces `E_INVALID_LIST_ITEM`.

## `route` and `prev` Route Relationships

`route` stores the route label or route ID. `prev` stores predecessor reaction references. The typechecker resolves `prev` through `resolveReactionPrevReferences`, with support for cross-document reactions through `reactionRouteContext`. Route validation includes typed-reference checks, route mismatch checks, cycle checks, and orphan checks.

Related diagnostics:

| code | trigger |
| --- | --- |
| `E_TYPED_REFERENCE_MISMATCH` | `prev` points to a non-reaction target |
| `W_REACTION_ROUTE_MISMATCH` | predecessor route differs from current route |
| `E_REACTION_ROUTE_CYCLE` | route graph contains a cycle |
| `W_REACTION_ROUTE_ORPHAN` | route contains an unconnected reaction |

## `chemistry_features` Extension References

`chemistry_features` is converted by `readChemistryFeatureRefs` into `chemistryFeatureRefs`. Feature kind is `molecule` inside molecule nodes and `reaction` inside reaction nodes. The parser currently marks each feature as `status: "available"`. This field supports future chemistry feature enrichment, training export, and external graph integration.

## Best Practice Example

Declare molecule and reaction objects before downstream result, analysis, procedure, sample, and artifact blocks. Use `@id` for typed relationships and keep route links explicit.

```md
:::chemd #mol-substrate
kind: molecule
name: benzyl alcohol
smiles: OCc1ccccc1
role: substrate
:::

:::chemd #mol-product
kind: molecule
name: benzaldehyde
smiles: O=Cc1ccccc1
role: product
:::

:::chemd #rxn-oxidation
kind: reaction
name: benzyl alcohol oxidation
route: route-oxidation
reactant: @mol-substrate | 1.00 mmol | 1.0 eq | limiting=true
product: @mol-product
reagents: MnO2
solvent: CH2Cl2
temperature: 25 C
time: 4 h
yield: 81 %
:::
```
