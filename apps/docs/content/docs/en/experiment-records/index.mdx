---
title: Experiment Record Modeling
description: Use Chemd to describe molecules, reactions, results, analyses, procedures, observations, samples, artifacts, and condition screens.
---

This page now follows the program-first language contract. Use `.chemd` modules, `meta`, declarations, `///` doc comments, and `/*md */` documentation regions for experiment records. Semantic facts come from molecule, reaction, result, analysis, sample, artifact, condition_screen, procedure, trace, observation, and agent run declarations.

See the [program-v1 language specification](/en/docs/program-v1/language).
