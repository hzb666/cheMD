---
title: '`:::use` Template Invocation Block'
description: '`:::use` invokes a template and supplies values; the resolver expands the template body.'
---

`:::use` is parsed by the block parser registry. The header argument is the template name, and all fields inside the block are stored as `values`.

## Syntax

```md
:::use analytical-confirmation
sample: sample-product
method: 1H NMR
:::
```

## Parameter Rules

`:::use` accepts arbitrary fields. Field values are strings; list values are joined with ` | `. The resolver validates values against the target template's `params`.

| validation | diagnostic |
| --- | --- |
| required parameter missing | `E_TEMPLATE_PARAM_MISSING` |
| `ref<kind>` target missing or wrong kind | `E_TEMPLATE_PARAM_TYPE_MISMATCH` |
| `quantity<class>` format or unit mismatch | `E_TEMPLATE_PARAM_TYPE_MISMATCH` |
| template name does not exist | `E_UNKNOWN_TEMPLATE` |

## Recommended Practice

Place a template call next to the context that uses it, and keep parameter names identical to the template definition.

```md
:::use analytical-confirmation
sample: @sample-product
method: HPLC
:::
```
