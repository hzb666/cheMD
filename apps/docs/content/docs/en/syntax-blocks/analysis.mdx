---
title: '`:::analysis` Analysis Block'
description: '`:::analysis` records TLC, NMR, chromatography, and MS evidence with type-specific structured fields.'
---

`:::analysis` records analytical evidence. The required field is `type`; type-specific fields determine which parser and diagnostics apply.

## Common Fields

| field | notes |
| --- | --- |
| `type` | `tlc`, `nmr`, `hplc`, `uplc`, `gc`, `lcms`, `gcms`, `ms`, `hrms`, `ir`, `uv` |
| `ref` | target sample, reaction, result, condition screen, or attempt |
| `time` | sampling or analysis time |
| `eluent` / `plate` / `visualization` | TLC method facts |
| `method` | method/profile reference or method name |
| `instrument` | instrument name |
| `solvent` / `frequency` | NMR metadata when not embedded in `spectrum` |
| `result` | linked result id or concise interpretation |
| `artifact` / `artifacts` | referenced raw data artifacts |
| `data` | unstructured fallback when no type-specific field applies |
| `notes` | free notes |

## TLC

```md
:::analysis #ana-tlc
type: tlc
ref: @sample-crude
method: @tlc-method-pe-ea-5-1

lane: sm | source=@mat-aryl
spot: 0.62

lane: rxn | source=@sample-crude
spot: sm
spot: 0.31 ^3(4) product
mess: 0.55 (3)

lane: prod | source=@sample-product
spot: 0.30
:::
```

`lane:` opens a lane. `spot`, `mess`, `base`, and `none` belong to the current lane until the next `lane:`. Lane labels and spot labels must be built-in roles or object references. Built-in roles include `sm`, `rxn`, `prod`, `int`, `blank`, `impurity`, and `unknown` / `unk`.

`spot: sm` references a known standard spot, not the lane. It reuses the referenced spot's Rf and marker facts, but not lane-level parameters. Ambiguous or missing standard spots are errors. `unknown` is only valid with an Rf, for example `spot: 0.42 unknown`.

## NMR

```md
:::analysis #ana-nmr
type: nmr
ref: @sample-purified
spectrum: 1H NMR (400 MHz, CDCl3)
peak: 7.68-7.59 (m, 2H, ArCH)
peak: 3.56 (tt, J = 9.1, 6.0 Hz, 1H, CH(C=O))
artifact: @art-nmr
:::
```

`spectrum:` provides spectrum-level defaults. `peak:` uses the common literature form `shift-or-range (multiplicity, coupling?, integration?, siteLabel?)`. Missing optional peak parts are preserved as unknown; an unparseable chemical shift is an error.

## Chromatography and MS

```md
:::analysis #ana-lcms
type: lcms
method: @lcms-esi-pos
peak: 6.4 min (97 %, product)
ion: m/z 124.1 ([M+H]+, product)
:::
```

HPLC/UPLC/GC peaks use `retention-time (area %, component)`. LCMS and GCMS can contain both `peak:` and `ion:`. MS/HRMS use `ion:`. LCMS with peaks but no ion is an error because it drops the mass-spec meaning.

## Diagnostics

| code | condition |
| --- | --- |
| `E_TLC_LANE_REQUIRED` | `spot`, `mess`, `base`, or `none` appears before `lane` |
| `E_TLC_LABEL_UNKNOWN` | TLC lane or spot label is not a role or reference |
| `E_TLC_SPOT_REFERENCE` | label-only spot cannot resolve one standard spot |
| `E_TLC_UNKNOWN_REFERENCE` | `spot: unknown` lacks an Rf and has no identity |
| `E_TLC_SPOT_LABEL_REQUIRED` | mixed/custom lane spot lacks a label |
| `E_ANALYSIS_FIELD_FOR_TYPE` | field is illegal for the selected analysis type |
| `E_ANALYSIS_SPECTRUM_CONFLICT` | NMR spectrum conflicts with explicit fields |
| `E_ANALYSIS_PEAK_SYNTAX` | peak lacks required shift or retention time |
| `E_ANALYSIS_ION_REQUIRED` | LCMS peak data lacks ion data |
| `E_ANALYSIS_ION_SYNTAX` | ion lacks m/z |
