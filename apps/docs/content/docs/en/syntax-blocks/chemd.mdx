---
title: '`:::chemd` Molecule and Reaction Block'
description: '`:::chemd` declares molecule identity and reactions; material and batch blocks carry physical inventory and lineage.'
---

`:::chemd` produces either a `molecule` or `reaction` node according to `kind` and field shape. `kind` can be omitted when fields are unambiguous. `mol` and `reac` are accepted as `kind` value aliases.

## Molecule Identity

Molecule nodes describe chemical identity only. Do not put reaction usage, amount, or equivalents on a molecule. Put those quantities on reaction participants.

```md
:::chemd #mol-substrate
kind: molecule
name: ethyl acetate
smiles: CCOC(C)=O
formula: C4H8O2
mw: 88.11 g/mol
:::
```

Identity fields include `name`, `smiles`, `canonical_smiles`, `cas`, `inchi`, `inchikey`, `formula`, `mw`, `role`, `caption`, and `chemistry_features`. At least one identity field is required by the typechecker. `inchi` must start with `InChI=`, and `inchikey` must use the standard uppercase 14-10-1 segment format. `amount` and `equivalents` on a molecule produce an error.

## Reaction Participants

Reaction nodes use canonical singular fields for participants. `reactant` and `product` can repeat. `reac` and `prod` are short aliases. Plural `reactants` and `products` remain simple list aliases only; do not attach amount, equivalents, or `limiting=true` to plural list values.

```md
:::chemd #rxn-main
kind: reaction
reactant: @mat-substrate-lot-a | 1.00 mmol | 1.0 eq | limiting=true
reactant: @mol-base | equiv=1.2
product: @mol-product
rxn_smiles: CCO.N>>CCN
solvent: MeCN
temperature: r.t. -> 60 C over 30 min
time: overnight
atmosphere: nitrogen
:::
```

Participant targets may be `molecule`, `material`, or `batch`. Amount can be written as `amount=1.0 mmol` or the shorter `1.0 mmol`. Equivalents can be written as `equiv=1.2`, `equiv=1.2 eq`, or `1.2 eq`. If any reactant has amount, equivalent, mass, volume, or `limiting=true`, exactly one reactant must be `limiting=true`. The limiting reactant must provide both amount and equivalent. Other stoichiometric reactants need at least amount or equivalent. Product participants cannot carry expected or isolated quantities; put outcome data in `:::result`.

## Material and Batch

Use `:::material` for purchased or inventory material. Use `:::batch` for material generated, split, purified, or otherwise produced during the experiment.

```md
:::material #mat-substrate-lot-a
molecule: @mol-substrate
supplier: Sigma
lot: A123
purity: 98 %
storage: flammable cabinet
:::

:::batch #batch-crude
source: @rxn-main
molecule: @mol-product
state: crude
mass: 120 mg
purity: 84 %
:::
```

`material.molecule` must reference a molecule. `batch.source` may reference a reaction, result, sample, or batch. `batch.molecule` may reference a molecule. Samples may point their `ref` at material, batch, reaction, result, sample, or another object.

| field | molecule | reaction | notes |
| --- | --- | --- | --- |
| `kind` | optional | optional | `molecule`, `reaction`, `mol`, or `reac`; inferred when fields are unambiguous |
| `name` | optional | optional | user-facing name |
| `smiles` | optional | not applicable | molecule identity |
| `canonical_smiles` | optional | not applicable | canonical structure string |
| `cas` | optional | not applicable | CAS registry string |
| `inchi` / `inchikey` | optional | not applicable | molecule identity |
| `formula` | optional | not applicable | formula text |
| `mw` | optional | not applicable | molecular weight text |
| `reactant` / `reac` | not applicable | repeatable | structured participant |
| `product` / `prod` | not applicable | repeatable | structured participant |
| `reactants` / `products` | not applicable | optional alias | simple reference/literal list only |
| `conditions` | not applicable | optional | string list |
| `route` | not applicable | optional | route ID or label |
| `prev` | not applicable | optional | predecessor reaction reference list |
| `reagents` / `catalyst` / `solvent` | not applicable | optional | raw condition fields |
| `temperature` / `time` / `pressure` | not applicable | optional | typed quantities |
| `atmosphere` | not applicable | optional | `nitrogen`, `argon`, `air`, `oxygen`, `inert`, or extension |

| `equation` / `rxn_smiles` | not applicable | optional | reaction identity strings; `reaction_smiles` is an alias of `rxn_smiles` |
| `chemistry_features` | optional | optional | feature IDs separated by `|` or `,` |

## Type Inference

The parser infers reaction from participant fields and reaction-only fields such as `reactant`, `product`, `rxn_smiles`, `reaction_smiles`, `solvent`, `temperature`, `time`, `yield`, or `conversion`. It infers molecule from identity fields such as `smiles`, `cas`, `inchi`, `inchikey`, `canonical_smiles`, `formula`, or `mw`. Unstable inference, invalid explicit `kind`, or field-shape conflict is an error.

## Quantity Surface

Unit-bearing quantities require a space between number and unit: `78 %`, `1.0 mmol`, `1.0 eq`, `30 min`. Compact forms such as `78%` are errors. Non-canonical unit casing such as `1 ml` is accepted with a warning and normalized to `1 mL`.

## Diagnostics

| code | condition |
| --- | --- |
| `E_INVALID_ID` | invalid block ID |
| `W_UNKNOWN_FIELD` | undeclared field |
| `E_INVALID_LIST_ITEM` | empty list item |
| `E_CHEMD_KIND_CONFLICT` | invalid `kind`, or explicit kind conflicts with field shape |
| `E_MOLECULE_IDENTITY_MISSING` | molecule has no identity field |
| `E_MOLECULE_REACTION_QUANTITY` | molecule contains reaction usage quantity |
| `E_INTEROP_SMILES_PARSE` | SMILES identity field cannot be parsed as a single token |
| `E_INTEROP_INCHI_FORMAT` | InChI identity field does not start with `InChI=` |
| `E_INTEROP_INCHIKEY_FORMAT` | InChIKey identity field does not use the standard segment format |
| `E_INTEROP_RXN_SMILES_PARSE` | reaction structure field is not a valid RXN SMILES surface |
| `E_REACTION_PARTICIPANT_SYNTAX` | structured participant facts are written on plural list aliases |
| `E_TYPED_REFERENCE_MISMATCH` | reference target has the wrong type |
| `E_STOICHIOMETRY_LIMITING` | limiting reactant rules are violated |
| `E_STOICHIOMETRY_QUANTITY_MISSING` | required participant amount/equivalent is missing |
