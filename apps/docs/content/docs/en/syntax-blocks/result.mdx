---
title: '`:::result` Result Block'
description: '`:::result` records outcome status, yield, conversion, selectivity, purity, and reaction/product links.'
---

`:::result` records an experimental outcome for a reaction or product.

## Syntax

```md
:::result #res-main
reaction: rxn-main
product: mol-product
status: success
yield: 82 %
conversion: 95 %
selectivity: 91:9
isolated_mass: 182 mg
product_state: white solid
purity: 98 %
notes: isolated after silica gel chromatography
:::
```

## Fields

| field | required | notes |
| --- | --- | --- |
| `status` | no | user-provided status such as success, partial, or failed |
| `yield` | no | yield text |
| `conversion` | no | conversion text |
| `selectivity` | no | selectivity text |
| `isolated_mass` | no | isolated mass text |
| `product_state` | no | product appearance or state |
| `purity` | no | purity text |
| `notes` | no | result notes |
| `ref` | no | generic target reference |
| `reaction` | no | reaction ID |
| `product` | no | product molecule ID |

## Required Fields and Defaults

`:::result` has no resolver-required fields and no parser defaults. When available, use `reaction` and `product` so export layers can build outcome and evidence links.

## Diagnostics

| code | condition |
| --- | --- |
| `E_INVALID_ID` | invalid block ID |
| `W_UNKNOWN_FIELD` | undeclared field |
| `E_TYPED_REFERENCE_MISMATCH` | a typechecked link points to the wrong object kind |

## Recommended Practice

Connect reaction, product, and result explicitly. Keep yield in a structured field as well as prose when both are needed.

```md
:::result #res-main
reaction: rxn-main
product: mol-biaryl
status: success
yield: 82 %
conversion: 96 %
selectivity: 93:7
isolated_mass: 210 mg
product_state: off-white solid
purity: 98 %
notes: product confirmed by NMR and HPLC
:::
```

For condition screening, use stable result IDs and reference them from the current `condition-varies` attempt through `result:`.

```md
:::result #res-var1
reaction: rxn-var1
status: partial
yield: 38 %
notes: starting material remained by TLC
:::
```
