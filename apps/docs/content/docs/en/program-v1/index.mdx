title: Program v1 Rewrite
description: Breaking-change contract for the program-first Chemd language.
---

Chemd program v1 rewrites Chemd from a legacy Markdown document format into a
program-first experiment language. One `.chemd` file is one module. Program
declarations are the semantic source of truth. Markdown is documentation only
when it appears in `///` doc comments or `/*md */` regions.

This section is the current program-first contract. Runtime packages,
renderers, exports, storage, language service, Desktop IDE, and docs now align
to these contracts.
