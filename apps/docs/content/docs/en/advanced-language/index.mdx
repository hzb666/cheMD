These chapters cover language features that depend on cross-block semantics or compiler stages. The focus stays on user-visible behavior while identifying parser, resolver, and typechecker boundaries.

## Reading Path

1. Start with references and templates, because they affect how source records share values.
2. Continue with normalization and derived expressions, because they explain typed values.
3. Read layout, resolver, compiler, runtime, workspace, and graph topics when source records need tooling integration.

## Chapters

- [References, Aliases, and Field Access](/en/docs/advanced-language/references-and-aliases): object references, field references, primary aliases, metadata, and template parameter references.
- [Templates and Reuse](/en/docs/advanced-language/templates): template definitions, calls, and expansion semantics.
- [Template Parameter Reference](/en/docs/advanced-language/template-parameters): detailed `string`, `ref<kind>`, `quantity<class>`, default types, and validation boundaries.
- [Normalization Semantics](/en/docs/advanced-language/normalization-semantics): reaction conditions, TLC lanes, status, analysis type, atmosphere, and relationship checks.
- [Derived Expressions](/en/docs/advanced-language/derived-expressions): `=` quantity field expressions, functions, and limits.
- [Layout and Presentation Syntax](/en/docs/advanced-language/layout-syntax): `:::col` and the language-presentational boundary.
- [Resolver and Compiler Semantics](/en/docs/advanced-language/resolver-compiler): indexes, reference resolution, template expansion, and required fields.
- [Compiler Semantic Path](/en/docs/advanced-language/compiler-semantics): processing from AST to exported outputs.
- [Runtime Preflight](/en/docs/advanced-language/runtime-preflight): run plans, runtime modes, capabilities, and manual confirmation strategy.
- [Workspace Symbol Index](/en/docs/advanced-language/workspace-index): multi-document symbol and reference indexing for editor and workspace use.
- [Training Graph and Reaction Map](/en/docs/advanced-language/training-graph-reaction-map): training export layers, graph index output, and reaction map layout.
