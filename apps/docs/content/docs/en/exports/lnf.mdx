---
title: LNF Export
description: Canonical lab-normal form for runtime, workflow, and typed experiment facts.
---

LNF is the canonical lab-normal form. It is exposed through CLI export:

```bash
pnpm chemd export ./examples/example.chemd --format lnf
```

The schema version is `chemd-lnf/v0.5`.

## Output Shape

`ChemdLnf` contains:

- `experiment.document`: ID, title, and date
- `experiment.entities.reactions`: reaction node IDs, participants, raw conditions, and normalized conditions
- `experiment.entities.results`: result node IDs, status, outcome quantities, and notes
- `experiment.semantic.typedGraph`: typed semantic graph
- `experiment.semantic.quantities`: normalized quantity records
- `experiment.workflow.steps`: canonical step nodes with params, inputs, outputs, dependencies, evidence, artifacts, effects, control path, source, provenance, raw text, and lowering confidence
- `experiment.workflow.controls`: canonical procedure control nodes
- `experiment.workflow.observations`: observation event nodes
- `experiment.workflow.diagnostics`
- `experiment.workflow.stepSources`: explicit step IDs, lowered step IDs, and observation-event source index
- `experiment.runtime`: run plan summary, state summary, and preflight when available
- `experiment.quality`: diagnostics and migration summary

## Example

```json
{
  "schemaVersion": "chemd-lnf/v0.5",
  "experiment": {
    "document": {
      "id": "exp-export-example",
      "title": "Export example",
      "date": "2026-05-21"
    },
    "entities": {
      "reactions": [
        {
          "nodeId": "rxn-main",
          "reactants": ["@mol-a | 1.0 mmol | 1.0 eq | limiting=true"],
          "products": ["@mol-b"],
          "conditions": { "solvent": "MeCN", "temperature": "60 C" },
          "normalizedConditions": {
            "solvent": { "raw": "MeCN", "normalized": "MeCN" },
            "temperature": { "raw": "60 C", "value": 60, "unit": "C" }
          }
        }
      ],
      "results": [
        {
          "nodeId": "res-main",
          "status": "success",
          "outcome": { "yield": { "raw": "78 %", "value": 78, "unit": "%" } }
        }
      ]
    },
    "workflow": {
      "steps": [
        {
          "stepId": "s-add",
          "family": "add",
          "params": {},
          "inputs": ["@mol-a"],
          "outputs": ["mixture-main"],
          "rawText": "add | id=s-add | inputs=@mol-a | outputs=mixture-main",
          "loweringConfidence": 1
        }
      ],
      "observations": [
        { "eventId": "e-color", "eventType": "color_change", "linkedStepId": "s-add" }
      ],
      "stepSources": {
        "explicitStepIds": ["s-add"],
        "loweredStepIds": [],
        "observationEvents": [{ "observationId": "obs-main", "eventId": "e-color" }]
      }
    }
  }
}
```

Use LNF when the consumer needs runtime/lab semantics instead of display HTML or broad training projections.
