---
title: LNF Export
description: Canonical lab-normal form for runtime, workflow, and typed experiment facts.
---

LNF is the canonical lab-normal form. It is exposed through CLI export:

```bash
pnpm chemd export ./examples/example.chemd --format lnf
```

The schema version is `chemd-lnf/v1.0`.

## Output Shape

`ChemdLnf` contains:

- `experiment.document`: ID, title, date, module name, and source language
- `experiment.source`: module, meta, declaration index, and documentation comments
- `experiment.entities`: program declaration entities for molecules, materials, batches, reactions, results, analyses, samples, artifacts, and condition screens
- `experiment.semantic.typedGraph`: typed semantic graph
- `experiment.semantic.quantities`: normalized quantity records
- `experiment.semantic.documentationLinks`: doc comment references and attachments
- `experiment.workflow.procedures`: procedure lowering summaries
- `experiment.workflow.steps`: canonical step nodes with params, inputs, outputs, dependencies, evidence, artifacts, effects, control path, source, provenance, raw text, and lowering confidence
- `experiment.workflow.controls`: canonical procedure control nodes
- `experiment.workflow.observations`: observation event nodes
- `experiment.workflow.traces`: trace declarations
- `experiment.workflow.diagnostics`
- `experiment.workflow.stepSources`: explicit step IDs, lowered step IDs, and observation-event source index
- `experiment.agent`: agent runs, patch proposals, and decisions
- `experiment.runtime`: run plan summary, state summary, and preflight when available
- `experiment.quality`: diagnostics and source completeness

## Example

```json
{
  "schemaVersion": "chemd-lnf/v1.0",
  "experiment": {
    "document": {
      "id": "exp-export-example",
      "title": "Export example",
      "date": "2026-05-21",
      "moduleName": "exp_export_example",
      "sourceLanguage": "chemd/program-v1"
    },
    "source": {
      "module": { "name": "exp_export_example" },
      "declarationIndex": [
        {
          "declarationId": "rxn_main",
          "declarationKind": "reaction",
          "docIds": []
        }
      ],
      "documentation": []
    },
    "entities": {
      "reactions": [
        {
          "declarationId": "rxn_main",
          "declarationKind": "reaction",
          "fields": {
            "solvent": { "type": "string", "value": "MeCN" }
          }
        }
      ]
    },
    "workflow": {
      "steps": [
        {
          "stepId": "s_add",
          "family": "add",
          "params": {},
          "rawText": "step s_add = add(inputs: [@mol_a])",
          "loweringConfidence": 1
        }
      ],
      "stepSources": {
        "explicitStepIds": ["s_add"],
        "loweredStepIds": [],
        "observationEvents": []
      }
    },
    "quality": {
      "sourceCompleteness": {
        "declarationCount": 4,
        "documentationCount": 0,
        "unresolvedReferenceCount": 0,
        "incompleteDeclarationCount": 0,
        "agentAuditRunCount": 0
      }
    }
  }
}
```

Use LNF when the consumer needs runtime/lab semantics instead of display HTML or broad training projections.
