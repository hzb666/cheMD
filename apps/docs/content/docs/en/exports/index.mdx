Chemd exports are projections of one compiled document or a set of compiled documents. They all start from the same parser, resolver, typechecker, step graph, runtime plan, and render profile pipeline, but each format keeps a different amount of structure.

## Format Overview

| Output | Main command or field | Use it for |
| --- | --- | --- |
| HTML | `compileChemd(source).html` | Browser preview, web publishing, and human review |
| JSON + semantic graph | `pnpm chemd export file.chemd --format json` | Structured AST-like output plus typed semantic graph |
| DOCX bridge | `compileChemd(source).docxBridge` | Markdown-to-DOCX conversion through the Node bridge |
| LNF | `pnpm chemd export file.chemd --format lnf` | Canonical lab/runtime facts, step graph, controls, and preflight summaries |
| Training full | `pnpm chemd export file.chemd --format training-full` | Audit-capable source, semantic, learning, and quality layers |
| Training understanding | `pnpm chemd export file.chemd --format training` | Sanitized training and reasoning projection |
| RAG | `pnpm chemd export file.chemd --format rag` | Retrieval chunks and search metadata |
| Graph index | `pnpm chemd graph *.chemd --format json` | Cross-document graph, reaction clusters, and reaction map input |

## Shared Compile Outputs

`compileChemd` returns these export-facing fields:

```ts
const result = compileChemd(source);

result.html;
result.json;
result.docxBridge;
result.lnf;
result.ragExport;
result.trainingUnderstanding;
result.trainingExport;
result.typedSemanticGraph;
result.stepGraph;
```

The CLI `export` command exposes `json`, `lnf`, `rag`, `training`, and `training-full`. HTML and DOCX are compile/app outputs rather than current CLI `export --format` values. The `graph` command compiles multiple files and builds a graph index from their training understandings.

Field value schema metadata is a compiler/tooling contract, not a standalone export format. It keeps editor completions and typed quantity fields aligned while preserving the existing JSON, semantic graph, training, RAG, HTML, DOCX, and LNF output shapes.

## Minimal Source Example

The examples in this section use a compact program-first source record:

```text
module exp_export_example

meta {
  id: "exp-export-example"
  title: "Export example"
  date: "2026-05-21"
  primary_reaction: @rxn_main
  primary_result: @res_main
}

molecule mol_a {
  name: "substrate A"
  smiles: "CCO"
}

molecule mol_b {
  name: "product B"
  smiles: "CC=O"
}

reaction rxn_main {
  reactants: [@mol_a]
  products: [@mol_b]
  solvent: "MeCN"
  temperature: 60 C
}

result res_main for @rxn_main {
  status: success
  yield: 78%
}

analysis ana_main for @res_main {
  type: nmr
  ref: @res_main
}

procedure proc_main for @rxn_main {
  evidence: [@res_main]
  step add = add(inputs: [@mol_a], outputs: [@mol_b])
}

observation obs_main for @rxn_main {
  notes: "yellow solution"
}
```
