---
title: Diagnostic Code Reference
description: Quick reference for common Chemd parser, resolver, typechecker, compiler, and runtime diagnostics.
---

The following reference lists common diagnostics by source and purpose. Use it to identify whether a problem comes from parsing, reference resolution, semantic validation, compilation, or runtime preparation.

## Syntax and Frontmatter

| Code | Meaning |
| --- | --- |
| `E_MISSING_REQUIRED_FRONTMATTER_KEY` | Missing `id`, `title`, or `date` |
| `E_INVALID_FRONTMATTER_VALUE` | Invalid frontmatter value type or structure |
| `W_DUPLICATE_FRONTMATTER_KEY` | Duplicate frontmatter key |
| `W_NON_ISO_FRONTMATTER_DATE` | Date does not match `YYYY-MM-DD` |
| `W_INVALID_FRONTMATTER_DATE_VALUE` | Date shape is valid but calendar value is invalid |
| `W_INVALID_FRONTMATTER_LINE` | Frontmatter line cannot be parsed |
| `E_INVALID_ID` | Block ID violates the ID rule |
| `W_LEGACY_BLOCK_KIND` | Legacy `:::molecule` or `:::reaction` surface is detected |
| `W_UNKNOWN_BLOCK` | Block type is not implemented |
| `W_UNTERMINATED_BLOCK` | Structured block is not closed |
| `W_UNKNOWN_FIELD` | Field is outside the allowed set for the block |
| `E_INVALID_LIST_ITEM` | List field contains an empty item |
| `W_UNSAFE_LINK_HREF` | Markdown link href fails the safe-href policy |
| `E_TLC_LANE_REQUIRED` | TLC lane item appears before a `lane:` line |
| `E_CONDITION_DSL_FIELD` | Condition screen contains an invalid section field |
| `E_CONDITION_DSL_ORDER` | Condition screen declarations appear after attempts |
| `E_CONDITION_ATTEMPT_ID` | Condition screen attempt ID is missing or duplicated |
| `E_CONDITION_DSL_DECLARATION` | Condition screen factor/outcome declaration is invalid |
| `E_CONDITION_ATTEMPT_DUPLICATE_FIELD` | Attempt repeats a declared factor or outcome field |
| `E_CONDITION_ATTEMPT_UNKNOWN_FIELD` | Attempt field was not declared as a factor or outcome |

## `:::chemd`

| Code | Meaning |
| --- | --- |
| `W_CHEMD_KIND_AMBIGUOUS` | `kind` omitted and cannot be inferred from fields |
| `E_CHEMD_KIND_CONFLICT` | Invalid `kind` or conflict between declared kind and field shape |
| `W_INVALID_CHEMD_IMPLICIT_VALUE` | Invalid implicit molecule SMILES body |

## Resolver

| Code | Meaning |
| --- | --- |
| `E_DUPLICATE_ID` | Duplicate object ID |
| `E_DUPLICATE_TEMPLATE` | Duplicate template name |
| `E_MISSING_REQUIRED_FIELD` | Missing resolver-required object field |

| `E_INTEROP_SMILES_PARSE` | SMILES identity field fails surface parsing |

| `E_INTEROP_INCHIKEY_FORMAT` | InChIKey does not match the standard 14-10-1 segment format |
| `E_INTEROP_RXN_SMILES_PARSE` | RXN SMILES field does not contain a valid `reactants>>products` surface |
| `E_REACTION_PARTICIPANT_MISSING` | Reaction is missing a reactant or product participant |

| `E_STOICHIOMETRY_LIMITING` | Limiting reactant rules are violated |

| `E_TLC_LABEL_UNKNOWN` | TLC spot or lane label is not a supported built-in label |
| `E_TLC_SPOT_REFERENCE` | TLC spot reference cannot be resolved uniquely |
| `E_TLC_UNKNOWN_REFERENCE` | TLC `unknown` reference cannot resolve to a known spot |
| `E_TLC_SPOT_LABEL_REQUIRED` | Mixed TLC lane contains an unlabeled spot |
| `E_ANALYSIS_FIELD_FOR_TYPE` | Analysis field is incompatible with the declared analysis type |
| `E_ANALYSIS_PEAK_SYNTAX` | Analysis peak cannot be parsed for the declared analysis type |
| `E_ANALYSIS_SPECTRUM_CONFLICT` | NMR spectrum metadata conflicts with explicit fields |
| `E_ANALYSIS_ION_REQUIRED` | LCMS/GCMS analysis has peaks but no ion data |
| `E_ANALYSIS_ION_SYNTAX` | MS ion line lacks an m/z value |
| `E_CONDITION_OUTCOME_MISSING` | Attempt is missing a declared outcome |
| `E_CONDITION_BASELINE_CONFLICT` | Declared outcome baseline conflicts with standard result |
| `E_CONDITION_OUTCOME_CONFLICT` | Attempt outcome conflicts with linked result |
| `E_DERIVED_EXPRESSION_INVALID` | Invalid derived expression |
| `W_REACTION_ROUTE_MISMATCH` | Previous reaction route mismatch |
| `E_REACTION_ROUTE_CYCLE` | Reaction route cycle |
| `W_REACTION_ROUTE_ORPHAN` | Isolated reaction inside a route |

## Procedure and Observation

| Code | Meaning |
| --- | --- |
| `E_STEP_INVALID_FAMILY` | Step family is not implemented |
| `E_STEP_MISSING_FIELD` | Required step structure field is missing |
| `E_STEP_PARAM_MISSING` | Required step family parameter is missing |
| `E_STEP_PARAM_INVALID` | Step family rejects the parameter |
| `E_STEP_PARAM_TYPE_MISMATCH` | Step family parameter value has the wrong schema type |
| `E_STEP_ID_DUPLICATE` | Duplicate step ID |
| `E_STEP_INVALID_REFERENCE` | `dependsOn` points to a missing step |
| `E_STEP_DEPENDENCY_CYCLE` | Step dependency graph contains a cycle |
| `E_PROCEDURE_CONTROL_SYNTAX` | Procedure control brace or line syntax is invalid |
| `E_PROCEDURE_CONTROL_UNCLOSED` | Procedure control block is missing a closing brace |
| `E_PROCEDURE_CONTROL_ID` | Procedure control ID is missing |
| `E_PROCEDURE_CONTROL_ID_DUPLICATE` | Procedure control ID is duplicated or collides with a step |
| `E_PROCEDURE_CONTROL_COUNT` | `repeat` count is missing or invalid |
| `E_PROCEDURE_CONTROL_BODY` | Control body is empty where children are required |
| `E_PROCEDURE_CONTROL_CONDITION` | Control condition is missing, ambiguous, or unresolved |
| `E_PROCEDURE_CONTROL_BRANCH` | Branch control lacks valid `case` or `default` structure |
| `E_PROCEDURE_CONTROL_PARALLEL` | Parallel control lacks at least two valid paths |
| `W_PROCEDURE_CONTROL_DYNAMIC` | Dynamic control requires runtime review |
| `E_OBSERVATION_EVENT_INVALID_TYPE` | Event type is not implemented |
| `E_OBSERVATION_LINKED_STEP_MISSING` | Event points to a missing step |
| `E_TRACE_PLAN_REFERENCE` | Trace block does not reference a procedure plan |
| `E_TRACE_EVENT_TIME` | Trace event time is not ISO datetime or not monotonic |
| `E_TRACE_EVENT_REFERENCE` | Trace event references an unknown step, control, artifact, analysis, or result |
| `E_TRACE_EVENT_PAYLOAD` | Trace event payload is missing required fields |
| `W_TRACE_STEP_STATE` | Trace step state order is suspicious or invalid for replay |

## Interoperability and Training Governance

| Code | Meaning |
| --- | --- |
| `E_INTEROP_RXN_SMILES_MISSING` | Reaction structure export was requested without `rxn_smiles` |
| `W_INTEROP_UNVERIFIED_IDENTITY` | Multiple molecule identity fields are present without an external consistency verifier |
| `W_INTEROP_PLACEHOLDER_NOT_COMPLIANT` | External standard export is a placeholder mapping, not a validator-backed compliant export |
| `E_TRAINING_PII_PRESENT` | Governance marks PII present, so only audit/full export is allowed |
| `W_TRAINING_RAG_NOT_ALLOWED` | `allowed_uses` does not include `rag` |
| `W_TRAINING_AUDIT_ONLY` | Governance allows audit use only |
| `W_TRAINING_SANITIZATION_DISABLED` | Non-audit training use is allowed while sanitization is disabled |
| `W_TRAINING_REVIEW_REQUIRED` | Training export has review-required quality or governance conditions |
| `E501` | Procedure lowering failed |
| `E504` | Analysis step is unbound |
| `E505` | Observation stage is ambiguous |
| `W_PROCEDURE_PROSE_LOWERED` | Procedure prose lowered heuristically into steps |
| `W_OBSERVATION_PROSE_LOWERED` | Observation prose lowered heuristically into events |
| `W805` | Low-confidence step extraction |
| `W806` | Observation prose could be represented as structured events |
| `I903` | Procedure lowering completed successfully |

## Repair Order

Fix errors before warnings. A stable order is frontmatter, block IDs, unknown fields, required fields, references, template parameters, quantities, step dependencies, and route graph diagnostics.
