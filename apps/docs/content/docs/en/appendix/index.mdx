The appendix provides quick-reference material. Users can confirm supported syntax while writing, and tool developers can check implementation boundaries.

## Chapters

- [Implementation Feature Inventory](/en/docs/appendix/feature-inventory): implemented language surface in the current codebase.
- [Syntax Summary](/en/docs/appendix/syntax-summary): frontmatter, inline syntax, structured blocks, and template syntax.
- [Quantity Units](/en/docs/appendix/quantity-units): quantity classes and units supported by typechecker and template parameter validation.
- [Syntax Aliases](/en/docs/appendix/syntax-aliases): Chemd field aliases, inline aliases, and accepted shorthand fields.
- [Diagnostic Code Reference](/en/docs/appendix/diagnostic-codes): common parser, resolver, typechecker, and compiler diagnostic codes.
