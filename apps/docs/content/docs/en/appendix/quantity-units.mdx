Chemd keeps the raw quantity text and computes canonical values for supported quantity classes during validation.

## Quantity Classes

| Class | Supported units | Canonical unit |
| --- | --- | --- |
| `amount` | `mmol`, `mol` | `mmol` |
| `mass` | `mg`, `g`, `kg` | `mg` |
| `volume` | `ml`, `mL`, `l`, `L` | `mL` |
| `temperature` | `C`, `°C`, `℃`, `K`, `F` | preserved by input class |
| `time` | `h`, `hr`, `hrs`, `min`, `mins`, `分钟`, `小时` | `h` |
| `pressure` | `bar`, `atm`, `psi` | `bar` |
| `concentration` | `M`, `mM` | `M` |
| `equivalent` | `equiv`, `eq` | `equiv` |
| `percent` | `%`, `percent` | `percent` |

| Object or syntax | Fields | Quantity class |

## Template Parameters

`quantity<class>` uses the resolver unit set for shape validation. Unclassified `quantity` accepts any supported quantity unit.

```md
params: amount: quantity<amount> | yield: quantity<percent>
```

## Derived-Expression Conversion

The derived-expression function `to_unit(quantity, unit)` supports mass, amount, and volume conversions:

- `mg`, `g`, `kg`
- `mmol`, `mol`
- `ml`, `l`

```md
isolated_mass: = to_unit(0.126 g, mg)
```

## Diagnostics

Quantity text that cannot be parsed for the target class produces `E403`. Percent values below 0 or above 100 produce `E402`. Expression evaluation failures produce `E_DERIVED_EXPRESSION_INVALID`.
