title: Quantity Units

Chemd keeps the raw quantity text and computes canonical values for supported quantity classes during validation.

## Quantity Classes

| Class | Supported units | Canonical unit |
| --- | --- | --- |
| `amount` | `mmol`, `mol` | `mmol` |
| `mass` | `mg`, `g`, `kg` | `mg` |
| `volume` | `mL`, `L` plus lowercase forms with warning | `mL` |
| `temperature` | `C`, `°C`, `℃`, `K`, `F` | preserved by input class |
| `time` | `h`, `hr`, `hrs`, `min`, `mins`, `分钟`, `小时` | `h` |
| `pressure` | `bar`, `atm`, `psi` | `bar` |
| `concentration` | `M`, `mM` | `M` |
| `equivalent` | `equiv`, `eq` | `equiv` |
| `percent` | `%`, `percent` | `percent` |
| `rate` | `mL/min`, `L/min` | `mL/min` |
| `rpm` | `rpm` | `rpm` |
| `ph` | `pH` | `pH` |

`rt` and `r.t.` are accepted temperature shorthands for room temperature. `overnight` is accepted as a time shorthand. Temperature programs use the same quantity parser, for example `r.t. -> 80 C over 30 min`.

Unit-bearing quantities require a space between value and unit. `78 %` and `1.0 mmol` are valid; `78%` and `1.0mmol` are errors. Reaction participant equivalents also accept a unitless `equiv=1.2` form. Non-canonical unit casing emits a warning when it can be normalized.

## Examples

Reaction participants can omit `amount=` when the segment carries an amount unit. Equivalents can use `eq`, `equiv`, or `equiv=...`. The limiting reactant must provide both amount and equivalent.

```md
:::chemd #rxn-main
reactant: @mat-substrate | 1.00 mmol | 1.0 eq | limiting=true
reactant: @mol-base | equiv=1.2
reac: @mol-catalyst | 0.05 eq
product: @mol-product
temperature: r.t. -> 80 C over 30 min
pressure: 1 bar
:::
```

Step parameters use the same parser. Rate and pH values are structured quantities, so they can participate in runtime preflight and typed graph output.

```md
:::procedure #proc-quantity
step: add | id=s-add | reagent=@mat-base | volume=2.0 mL | rate=0.5 mL/min
step: mix | id=s-stir | rpm=600 rpm | duration=30 min
step: observe | id=s-ph | ph=pH 7.2
step: heat | id=s-heat | temperature=r.t. -> 80 C over 30 min
:::
```

## Template Parameters

`quantity<class>` uses the resolver unit set for shape validation. Unclassified `quantity` accepts any supported quantity unit.

```md
params: amount: quantity<amount> | yield: quantity<percent>
```

## Derived-Expression Conversion

The derived-expression function `to_unit(quantity, unit)` supports mass, amount, and volume conversions:

- `mg`, `g`, `kg`
- `mmol`, `mol`
- `mL`, `L`

```md
isolated_mass: = to_unit(0.126 g, mg)
```

## Diagnostics

Quantity text that cannot be parsed for the target class produces `E403`. Compact number-unit syntax also produces `E403`. Percent values below 0 or above 100 produce `E402`. Non-canonical unit casing produces `W_QUANTITY_UNIT_CASING`. Expression evaluation failures produce `E_DERIVED_EXPRESSION_INVALID`.
