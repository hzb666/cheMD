The following content is a quick reference for users. Detailed semantics are defined by the topic pages and the current implementation.

## File and Frontmatter

```md
---
id: exp-id
title: Experiment title
date: 2026-04-24
primary_reaction: rxn-main
primary_result: res-main
tags:
  - synthesis
---
```

`id`, `title`, and `date` are required. `primary_*` fields provide prose aliases. `tags` is an array of strings.

## Inline Syntax

| Syntax | Purpose |
| --- | --- |
| `@id` | Object reference |
| `@id.field` | Object field reference |
| `@reaction.field` | Primary reaction alias |
| `@meta.field` | Frontmatter field reference |
| `@param.name` | Template parameter reference |
| `:chem[...]` | Inline chemistry expression |
| `` `code` `` | Inline code |
| `[label](href)` | Markdown link, checked by the safe-href policy |

## Structured Blocks

```md
:::block-type #optional-id
field: value
list_field: value-a | value-b
multi: a ;; other: b
:::
```

Block types use lowercase letters, digits, underscores, and hyphens. Field names use lowercase letters, digits, and underscores. List fields support `|` and comma separators. Empty items produce diagnostics.

## Supported Blocks

`:::template` is supported as a parser special-case. The registered block parser set contains the other top-level blocks listed here.

| Block | Semantics |
| --- | --- |
| `:::chemd` | molecule or reaction |
| `:::material` | inventory material |
| `:::batch` | generated or purified batch |
| `:::result` | experiment result |
| `:::analysis` | analytical data |
| `:::procedure` | experimental procedure |
| `:::trace` | runtime trace |
| `:::observation` | observation record |
| `:::sample` | sample |
| `:::artifact` | artifact |
| `:::condition-varies` | condition screen |
| `:::template` | template definition, parser special-case |
| `:::use` | template invocation |
| `:::col`, `:::col-2` | column layout |

`:::step` and `:::event` are nested syntaxes inside procedure and observation blocks.

Reaction participants should use repeatable `reactant` / `product` fields or compact aliases `reac` / `prod` when carrying amount, equivalent, mass, volume, or `limiting=true`.

## Template

```md
:::template template-name
bind: reaction=primary_reaction
params:
  - sample: ref<sample>
  - amount: quantity<amount>

Sample @param.sample used @param.amount in @reaction.name.
:::

:::use template-name
sample: @sample-main
amount: 1.00 mmol
:::
```

## Step

```md
:::procedure #proc-main
step: charge | id=s1 | inputs=@mat-a | amount=1.00 mmol
step: heat | id=s2 | temperature=80 C | duration=2 h | dependsOn=s1
repeat: wash-cycle | count=2 {
  step: wash | solvent=brine | volume=10 mL
}
until: monitor-tlc | condition=@ana-tlc.status == complete | max_iterations=3 {
  step: analyze | id=s-tlc | type=tlc
}
wait: operator-approval | condition=operator.confirmed | timeout=10 min
abort_if: unsafe-temperature | condition=sensor.temperature > 90 C
:::
```

Nested form:

```md
:::procedure #proc-main
:::step
family: analyze
id: s-analyze
analysisType: HPLC
:::
:::
```

## Event

```md
:::observation #obs-main
event: color_change | id=e1 | linkedStep=s2 | value=yellow
:::
```

Supported event types: `color_change`, `precipitation`, `gas_evolution`, `phase_change`.

## Trace

```md
:::trace #trace-run
plan: @proc-main
mode: human-run
event: started | at=2026-05-20T09:00:00Z | step=s1
event: completed | at=2026-05-20T09:12:00Z | step=s1
:::
```

## Column Layout

```md
:::col-2
col: Left narrative with @reaction.solvent.
col: {
:::result #res-main
status: success
yield: 80 %
:::
}
:::
```

Column count comes from `:::col-2` or `:::col 2`. A mismatch between child count and column count produces `W_COL_COUNT_MISMATCH`.

Chemd source files use the `.chemd` extension.
