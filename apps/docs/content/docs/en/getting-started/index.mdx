## Starting Example

```md validate
module exp_minimal

meta {
  id: "exp-minimal"
  title: "Minimal Chemd experiment"
  date: "2026-04-24"
  primary_reaction: @rxn_main
  primary_result: @res_main
}

molecule mol_a {
  name: "substrate A"
  smiles: "CCO"
}

molecule mol_b {
  name: "product B"
  smiles: "CC=O"
}

reaction rxn_main {
  reactants: [@mol_a]
  products: [@mol_b]
  temperature: 25 C
  time: 1 h
}

result res_main for @rxn_main {
  product: @mol_b
  status: success
  yield: 65%
}
```

The example covers the core fields: document `id`, `title`, `date`, molecule identity, reaction participants, and a result linked to the reaction.
