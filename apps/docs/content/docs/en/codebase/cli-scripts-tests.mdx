Root `package.json` exposes CLI, development, test, lint, and typecheck commands.

## CLI

Root command:

```bash
pnpm chemd
```

The command runs `node packages/cli/bin/chemd.mjs`.

## Scripts

The `scripts` directory contains these categories:

| Category | Examples |
| --- | --- |
| Development startup | `dev-demo.mjs` |
| PostgreSQL | `postgres-migrate.mjs`, `postgres-smoke.mjs`, `postgres-tools.mjs` |
| Desktop smoke | `desktop-runtime-smoke.mjs`, `desktop-offline-core-smoke.mjs`, `desktop-release-readiness.mjs` |
| Diagnostics bundle | `desktop-diagnostics-bundle.mjs` |

## Test Commands

Root commands include:

```bash
pnpm run test
pnpm run test:scripts
pnpm run test:py
pnpm run lint
pnpm run typecheck
```
