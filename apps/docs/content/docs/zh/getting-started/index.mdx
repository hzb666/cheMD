这一组章节建立 Chemd 源文件的基本模型。使用者应先确认文档边界、frontmatter 职责、正文与结构化块关系，再进入字段和诊断细节。

## 章节

- [Chemd 语言总览](/zh/docs/getting-started/language-overview)：文件扩展名、使用者输入层、AST 层、编译输出层和实现支持范围。
- [Chemd 源文件模型](/zh/docs/getting-started/document-model)：记录级元数据、对象节点、行内引用、模板节点和编译结果之间的关系。

## 推荐起始样例

```md validate
---
id: exp-minimal
title: Minimal Chemd experiment
date: 2026-04-24
primary_reaction: rxn-main
primary_result: res-main
---

:::chemd #mol-a
name: substrate A
smiles: CCO
:::

:::chemd #mol-b
name: product B
smiles: CC=O
:::

:::chemd #rxn-main
reactant: @mol-a | 1.0 mmol | 1.0 eq | limiting=true
product: @mol-b
temperature: 25 C
time: 1 h
:::

:::result #res-main
reaction: @rxn-main
product: @mol-b
status: success
yield: 65%
:::
```

该样例覆盖核心字段：文档 `id`、`title`、`date`，molecule identity，reaction participant，以及与 reaction 相连的 result。
