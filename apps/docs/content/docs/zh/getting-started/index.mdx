这一组章节建立 Chemd 源文件的基本模型。使用者应先确认 module、metadata、declarations、references 和 documentation regions，再进入字段和诊断细节。

## 章节

- [Chemd 语言总览](/zh/docs/getting-started/language-overview)：文件扩展名、使用者输入层、AST 层、编译输出层和实现支持范围。
- [Chemd 源文件模型](/zh/docs/getting-started/document-model)：记录级元数据、对象节点、行内引用、模板节点和编译结果之间的关系。

## 推荐起始样例

```md validate
module exp_minimal

meta {
  id: "exp-minimal"
  title: "Minimal Chemd experiment"
  date: "2026-04-24"
  primary_reaction: @rxn_main
  primary_result: @res_main
}

molecule mol_a {
  name: "substrate A"
  smiles: "CCO"
}

molecule mol_b {
  name: "product B"
  smiles: "CC=O"
}

reaction rxn_main {
  reactants: [@mol_a]
  products: [@mol_b]
  temperature: 25 C
  time: 1 h
}

result res_main for @rxn_main {
  product: @mol_b
  status: success
  yield: 65%
}
```

该样例覆盖核心字段：文档 `id`、`title`、`date`，molecule identity，reaction participant，以及与 reaction 相连的 result。
