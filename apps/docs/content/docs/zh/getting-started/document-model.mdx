Chemd 源文件由 frontmatter、Markdown 正文和结构化块组成。解析入口先读取 frontmatter，再解析正文块，最后生成 `ChemdDocument`。

## 文档根节点

当前 AST 根节点包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | `"document"` | 固定文档类型 |
| `meta` | `ChemdMeta` | frontmatter 解析结果 |
| `children` | `ChemdNode[]` | Markdown 节点和结构化节点 |
| `diagnostics` | `Diagnostic[]` | 解析和解析增强阶段产生的问题 |
| `source` | `string` | 原始源码，可选 |
| `renderSelection` | `RenderSelection` | 渲染 profile 与 overrides，可选 |

解析会先读取 frontmatter，得到文档元数据、正文、诊断和可选渲染选择；随后正文被解析为有序子节点。

## 必需 frontmatter

`id`、`title`、`date` 是必需键。缺失时解析器保留默认值，并向 `diagnostics` 写入缺失字段诊断。

```yaml
---
id: exp-suzuki-screen-001
title: Suzuki coupling solvent screen
date: 2026-04-24
---
```

`date` 推荐使用 `YYYY-MM-DD`。解析器会检查格式，并确认日期是真实日历日期。

## 常用扩展字段

frontmatter 允许标量扩展字段。当前 resolver 对 `primary_*` 字段有语义处理。

| 字段 | 说明 |
| --- | --- |
| `primary_reaction` | 主 reaction 对象 ID |
| `primary_result` | 主 result 对象 ID |
| `primary_product` | 主 product/molecule 对象 ID |
| `primary_sample` | 主 sample 对象 ID |
| `primary_molecule` | 主 molecule 对象 ID |
| `primary_analysis` | 主 analysis 对象 ID |
| `tags` | 字符串数组 |
| `render_profile` | 渲染 profile ID |
| `render_overrides` | 单层渲染覆盖对象 |

```yaml
---
id: exp-total-synthesis-step-07
title: Total synthesis step 07
date: 2026-04-24
primary_reaction: rxn-step-07
primary_result: res-step-07
tags:
  - total-synthesis
  - route-taxol-a
render_profile: publication-acs
render_overrides:
  structure.bondLineWidth: 2.1
---
```

## 块 ID

结构化块 ID 写在块头中，以 `#` 开头。

```md
:::result #res-main
status: success
yield: 76 %
:::
```

ID 必须匹配 `[a-zA-Z][a-zA-Z0-9_-]*`。解析器在 `readStructuredBlockId` 中校验该规则，并在无效时产生 `E_INVALID_ID`。

## 字段行与列表

块内字段采用 `key: value`。字段名以小写字母开始，后续支持小写字母、数字和下划线。

```md
reactant: @mol-aryl | 1.0 mmol | 1.0 eq | limiting=true
reac: @mol-boron | 1.2 eq
product: @mol-product
conditions: Cu catalyst | air | 80 C | 4 h
```

列表字段使用 `|` 分隔。当前列表字段包括 `reactants`、`products`、`reactant`、`product`、`reac`、`prod`、`conditions`、`params`，以及 `:::chemd` 中的 `prev`。reaction participant 推荐使用单数结构化字段 `reactant` / `product` 或紧凑别名 `reac` / `prod`；复数别名只是简单列表，不承载 amount、equivalent、mass、volume 或 `limiting=true`。

同一物理行可以用 `;;` 写多个字段段。该写法适合紧凑记录，但长实验记录推荐每行一个字段。

```md
solvent: MeCN ;; temperature: 40 C ;; time: 2 h
```
