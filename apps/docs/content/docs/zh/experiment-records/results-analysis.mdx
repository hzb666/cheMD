## `:::result` 结果块

`:::result` 生成 `ResultNode`。当前 resolver 对 result 没有通用必填字段校验，但高质量记录通常包含结果 ID、关联字段和至少一个结果指标。

## `ref`、`reaction`、`product` 关联关系

`ref`、`reaction` 和 `product` 都作为字符串字段保存。当前 typechecker 优先使用 `reaction`，缺少 `reaction` 时把 `ref` 作为 reaction 引用后备值。`product` 指向 product molecule。

## `yield`、`conversion`、`selectivity`、`purity`

这些字段在 AST 中保留原文，随后由 typechecker 按 percent quantity 解析。百分号值是紧凑 literal，例如 `82%`；`82 %` 这类带空格写法是 error。

## `:::analysis` 分析块

`:::analysis` 生成 `AnalysisNode`。字段 `type` 会映射为 AST 中的 `type_name`。

```md
:::analysis #ana-hplc-main
type: hplc
ref: @res-main
method: HPLC area normalization
instrument: Agilent 1260
peak: 6.4 min (97%, product)
data: Main peak at 6.4 min with trace impurity.
:::
```

## TLC lane

TLC 使用显式 `lane:` section。lane 内可以写 `spot:`、`mess:`、`base:` 或 `none`。只有一个 label 的 `spot:`，例如 `spot: sm`，表示引用其他 lane 中已确定的 spot；无法解析或存在冲突时会报错。

## NMR / HPLC 等通用分析写法

NMR 使用 `spectrum:` 与 `peak:` 行。HPLC、UPLC、GC 使用 `peak:` 行。LCMS 与 GCMS 使用 `peak:` 和 `ion:` 行。

## analysis 必填字段与 TLC 默认值

analysis 需要 `type_name`。TLC 缺少 `plate` 时默认 `silica gel GF254`，缺少 `visualization` 时默认 `UV 254 nm`。

## result 类型检查清单

typechecker 对 result 执行以下处理：`status` 归一化为 success、partial、failed 或 unknown；`yield`、`conversion`、`selectivity` 和 `purity` 解析为 percent quantity；`isolated_mass` 解析为 mass quantity；`reaction` 或后备 `ref` 按 reaction 引用解析；`product` 按 molecule 引用解析。

result 与 linked reaction 的关系校验包含两类：`product` 必须出现在 linked reaction 的 products 中；result 的 `yield`、`conversion`、`selectivity` 若与 reaction 同名字段不一致，会产生 `E_RESULT_REACTION_CONFLICT`。

## analysis 类型检查清单

analysis 的 `type` 在 AST 中保存为 `type_name`，typechecker 通过 `normalizeAnalysisType` 识别 `tlc`、`nmr`、`hplc`、`uplc`、`gc`、`lcms`、`lc-ms`、`gcms`、`gc-ms`、`ms`、`hrms`、`ir`、`uv` 和 `uv-vis`。未命中 alias 的 type 作为 extension 保存。

TLC analysis 会通过 `classifyTlcAnalysis` 构建 normalized TLC 数据。`lane:`、`spot:`、`mess:`、`base:`、`none` 与 `eluent`、`plate`、`visualization` 共同参与 TLC 结构化输出。

## 推荐实践示例

result 应连接 reaction 和 product，analysis 应连接 result 或 sample。只有实际使用默认 plate 与 visualization 时才依赖 TLC 默认值。

```md
:::result #res-main
reaction: @rxn-main
product: @mol-product
status: success
yield: 82%
isolated_mass: 120 mg
purity: 98%
notes: isolated after silica gel chromatography
:::

:::analysis #ana-tlc-main
type: tlc
ref: @res-main
eluent: petroleum ether/ethyl acetate 5:1
plate: silica gel GF254
visualization: UV 254 nm
lane: sm
spot: 0.62
lane: rxn
spot: sm
spot: 0.31 ^3(4) prod
lane: prod
spot: 0.31
result: product spot observed, starting material consumed
:::

:::analysis #ana-nmr-product
type: nmr
ref: @sample-product
spectrum: 1H NMR (400 MHz, CDCl3)
peak: 7.68-7.59 (m, 2H, ArCH)
peak: 7.14-7.03 (m, 2H, ArCH)
peak: 3.56 (tt, J = 9.1, 6.0 Hz, 1H, CH(C=O))
artifact: @art-nmr-1h
:::

:::analysis #ana-hplc-product
type: hplc
ref: @res-main
instrument: Agilent 1260
method: C18 gradient
peak: 6.4 min (98%, product)
:::

:::analysis #ana-lcms-product
type: lcms
ref: @sample-product
method: ESI positive
peak: 6.4 min (98%, product)
ion: m/z 321.1234 [M+H]+
:::
```
