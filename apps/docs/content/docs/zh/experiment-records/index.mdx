这一组章节面向实验记录使用者，按实验记录的自然组织方式说明 Chemd 对象。每个主题对应使用者需要维护的证据、关联关系和最佳实践样例。

## 记录构建顺序

1. 声明 molecule 与 reaction 对象。
2. 增加 result 与 analysis。
3. 增加 procedure 与 observation，并使用显式 step ID 和 event ID。
4. 增加 sample、artifact 与证据链。
5. 在实验需要时增加 condition screen、route link 和多文档组织。
