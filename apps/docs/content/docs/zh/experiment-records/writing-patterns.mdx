## 一步合成记录

一步合成通常包含 reagent molecule、product molecule、main reaction、main result、procedure、analysis、sample 和 artifact。`best-practice-one-step-synthesis.chemd` 展示该组合。

```md
---
id: one-step-example
title: One-step oxidation record
date: 2026-05-19
primary_reaction: rxn-main
primary_result: res-main
---

:::chemd #substrate
kind: molecule
smiles: CCO
name: ethanol
:::

:::chemd #product
kind: molecule
smiles: CC=O
name: acetaldehyde
:::

:::chemd #rxn-main
kind: reaction
reactants: substrate
products: product
solvent: DCM
temperature: 0 C
time: 2 h
:::

:::result #res-main
ref: rxn-main
status: success
yield: 62 %
:::

:::procedure #proc-main
reaction: rxn-main
step: add | id=s-add-oxidant | reagent=oxidant | temperature=0 C | mode=dropwise
step: hold | id=s-hold | duration=2 h | dependsOn=s-add-oxidant
step: quench | id=s-quench | reagent=sodium sulfite | dependsOn=s-hold
:::
```

最小稳定记录应显式声明对象 ID，并通过 `primary_reaction` 与 `primary_result` 指向主反应和主结果。

## 总合成路线步骤

总合成 fixture 使用多个 reaction，并通过 `route` 和 `prev` 表达路线关系。每个步骤保留独立 result 和 procedure，便于 graph export 推断路线边。

```md
:::chemd #rxn-step-1
kind: reaction
reactants: starting-material
products: intermediate-1
route: route-a
:::

:::chemd #rxn-step-2
kind: reaction
reactants: intermediate-1
products: final-product
route: route-a
prev: rxn-step-1
:::

:::result #res-step-2
ref: rxn-step-2
status: success
yield: 48 %
:::
```

`route` 保存路线名，`prev` 保存上游 reaction ID。多步路线中每一步仍应具备独立 result，避免把整条路线的产率混写到单一节点。

## 条件筛选记录

条件筛选记录应建立 baseline reaction、attempt reaction、attempt result 和 `condition-varies`。`varN` 连接 attempt reaction，`resN` 连接 attempt result。

```md
:::condition-varies #cv-base
standard: rxn-baseline
condition: solvent=THF | temperature=25 C
varies: solvent | temperature
var1: id=attempt-mecn-40 | reaction=rxn-mecn-40 | solvent=MeCN | temperature=40 C
res1: res-mecn-40
note1: highest conversion in the first screen
:::
```

筛选表应保留 baseline 条件和变化维度。attempt 结果较复杂时，使用独立 `:::result` 保存产率、转化率、选择性和纯度。

## 分析驱动记录

分析驱动记录用 `:::analysis` 连接 reaction、result 或 condition attempt。TLC 使用 `pN` lane。HPLC、NMR 等分析使用 `instrument`、`method`、`result` 和 `data`。

```md
:::analysis #ana-tlc-screen
type: tlc
ref: cv-base.attempt-mecn-40
eluent: petroleum ether/ethyl acetate 4:1
p1: sm rf=0.20 ^ (2)
p2: product rf=0.55 v (4)
result: product spot dominant after 2 h
:::

:::analysis #ana-hplc-product
type: hplc
ref: res-main
instrument: Agilent 1260 Infinity II
method: C18 gradient 10-90% MeCN
data: reports/hplc/main-product.pdf
result: purity 96 %
:::
```

TLC lane 中的 `sm`、`product`、`rf`、方向标记和强度标记会被解析为结构化 lane item。HPLC、NMR、LCMS 等分析保留通用字段。

## 样品追踪记录

样品追踪用 `derived_from`、`aliquot_of` 和 `batch_of` 表达来源。`artifacts` 连接谱图、图片和报告。

```md
:::sample #sample-crude
ref: rxn-main
name: Crude reaction mixture
batch: batch-main
:::

:::sample #sample-purified
ref: res-main
name: Purified main product
derived_from: sample-crude
batch_of: batch-main
artifacts: art-nmr-1h | art-hplc-report
:::
```

样品追踪的核心是稳定 ID。`derived_from` 记录制备来源，`batch_of` 记录批次归属，`artifacts` 记录后续证据文件。

## 附件证据记录

附件证据使用 `kind`、`ref`、`path`、可选 `checksum` 和 `instrument`。NMR、TLC、LCMS、图片和报告文件适合作为 evidence chain 的末端节点，以便追溯到样品、分析或结果。

```md
:::artifact #art-nmr-1h
kind: nmr
ref: sample-purified
path: data/nmr/product-1h.jdx
checksum: sha256:9c8a7f1e
instrument: Bruker Avance 400
notes: 1H NMR in CDCl3
:::
```

artifact 只保存附件元数据。分析结论应放在 `:::analysis`，文件位置和采集设备应放在 `:::artifact`。

## 多文档路线组织

`pnpm chemd graph <file...>` 编译多份文档，再基于 training understanding 构建 graph index。多文档路线应保持稳定 document ID、显式 reaction ID 和一致的 route 命名。

```md
---
id: route-a-step-2
title: Route A step 2
date: 2026-05-19
primary_reaction: rxn-route-a-step-2
---

:::chemd #rxn-route-a-step-2
kind: reaction
reactants: intermediate-1
products: final-product
route: route-a
prev: route-a-step-1#rxn-route-a-step-1
:::
```

typechecker 的 scoped ID 支持 `documentId#objectId` 形式。跨源文件路线应使用稳定 document ID 和对象 ID，便于 graph index 聚合。

## 推荐实践示例

先建立能够通过验证的最小完整记录，再根据实验实际需要增加 analysis、sample、artifact、route 和 screening 结构。

```md
---
id: exp-pattern-minimal
title: Minimal complete pattern
date: 2026-05-19
primary_reaction: rxn-main
primary_result: res-main
---

:::chemd #mol-start
kind: molecule
smiles: CCO
:::

:::chemd #mol-product
kind: molecule
smiles: CC=O
:::

:::chemd #rxn-main
kind: reaction
reactants: @mol-start
products: @mol-product
:::

:::result #res-main
reaction: rxn-main
product: mol-product
status: success
yield: 70 %
:::
```
