## `:::sample` 样品块

`:::sample` 生成 `SampleNode`。resolver 要求 sample 包含 `name`。

```md
:::sample #sample-crude-main
ref: @rxn-main
name: Crude reaction mixture after aqueous workup
sample_id: CR-2026-001
batch: batch-main-001
purity: 82 %
notes: Brown oil before purification
:::
```

`ref` 可指向反应、结果或其他对象 ID。`sample_id` 和 `batch` 按字符串保存，适合记录实验台账编号和批次编号。`purity` 会进入 typechecker 的 quantity 解析流程，支持百分数单位。

## `derived_from`、`aliquot_of`、`batch_of`

这些字段按字符串保存。它们用于表达样品派生、取样和批次关系。

```md
:::sample #sample-batch-var1
ref: @rxn-var1
name: Isolated product batch from var1
batch: batch-var1
:::

:::sample #sample-aliquot-var1
ref: @rxn-var1
name: TLC aliquot from var1
aliquot_of: sample-batch-var1
artifacts: art-tlc-var1
:::

:::sample #sample-nmr-var1
ref: @res-var1
name: NMR tube sample from isolated product
derived_from: sample-batch-var1
batch_of: batch-var1
artifacts: art-nmr-var1
:::
```

`derived_from` 适合表达制备来源，`aliquot_of` 适合表达取样来源，`batch_of` 适合表达批次归属。当前实现不强制这些字段指向已存在对象；为保持证据链可追踪，推荐填入显式 sample 或 batch ID。

## `artifacts` 字段

`artifacts` 是 sample 的列表字段，可用 `|` 或 `,` 分隔。解析后写入 `artifacts: string[]`。

```md
:::sample #sample-characterized
name: Purified product for characterization
artifacts: art-nmr-1h | art-nmr-13c | art-hplc-report
:::
```

当附件较少时可使用一行列表。附件较多时，推荐保持每个 artifact 具备独立 ID，并在 sample 中只维护 ID 清单。

## `:::artifact` 附件块

`:::artifact` 生成 `ArtifactNode`。resolver 要求 `kind` 和 `path`。

```md
:::artifact #art-nmr-1h
kind: nmr
ref: @sample-characterized
path: data/nmr/CR-2026-001-1H.jdx
instrument: Bruker Avance 400
notes: 1H NMR in CDCl3
:::
```

`kind` 描述附件类型，`ref` 连接样品、分析或结果，`path` 保存文件路径。resolver 只校验 `kind` 和 `path` 是否存在。

## 文件路径、`checksum`、`instrument`

artifact 字段包括 `kind`、`ref`、`path`、`checksum`、`instrument`、`notes` 和 `chemistry_features`。解析器不检查文件是否存在，也不验证 checksum 格式。

```md
:::artifact #art-hplc-report
kind: hplc
ref: @ana-hplc-main
path: reports/hplc/main-product.pdf
checksum: sha256:2b6f1c7f0d9e4c0a
instrument: Agilent 1260 Infinity II
notes: Exported integration report
:::
```

路径建议使用仓库内相对路径。`checksum` 可保存任意校验字符串；当前语言层不限制算法前缀。`instrument` 用于记录采集设备或分析平台。

## 样品到结果、分析、附件的证据链

推荐用 `sample.ref` 指向 reaction 或 result，用 `sample.artifacts` 指向附件，用 `artifact.ref` 指向 sample、analysis 或 result。同一模式适用于 NMR、TLC、LCMS、图片和报告证据。

```md
:::result #res-main
ref: @rxn-main
status: success
yield: 68 %
purity: 96 %
:::

:::sample #sample-main
ref: @res-main
name: Purified main product
derived_from: sample-crude-main
artifacts: art-nmr-1h | art-hplc-report
:::

:::analysis #ana-hplc-main
type: hplc
ref: @sample-main
instrument: Agilent 1260 Infinity II
method: C18 gradient 10-90% MeCN
result: purity 96 %
data: reports/hplc/main-product.pdf
:::

:::artifact #art-hplc-report
kind: hplc
ref: @ana-hplc-main
path: reports/hplc/main-product.pdf
instrument: Agilent 1260 Infinity II
:::
```

该写法形成 `result -> sample -> analysis -> artifact` 的证据链。结果字段保存结论，sample 保存实物来源，analysis 保存方法与数据摘要，artifact 保存文件位置。

## 推荐实践示例

sample 用于记录实物身份和来源，artifact 用于记录文件证据，分析解释应写入 `:::analysis`。

```md
:::sample #sample-purified
ref: @res-main
name: Purified product
sample_id: P-2026-0519-01
derived_from: rxn-main
artifacts: art-nmr-1h | art-hplc-report
:::

:::artifact #art-nmr-1h
kind: nmr
ref: @sample-purified
path: data/nmr/product-1h.jdx
checksum: sha256:9c8a7f1e
instrument: Bruker Avance 400
:::
```
