## 条件筛选模型

`:::condition-varies` 用 factor 声明输入变量，用 outcome 声明测量输出，并用 `attempt:` 分段记录每次尝试。所有 `factor:` 和 `outcome:` 必须写在第一个 `attempt:` 之前。`attempt:` 之后的字段归属于该 attempt，直到下一个 `attempt:`。

```md
:::condition-varies #cv-solvent
standard: @rxn-baseline

factor: solvent | baseline=THF
factor: temperature | baseline=25 C
outcome: yield | baseline=68 %
outcome: conversion | baseline=85 %

attempt: mecn-40
reaction: @rxn-mecn-40
result: @res-mecn-40
solvent: MeCN
temperature: 40 C
yield: 72 %
conversion: 90 %
note: clean conversion by TLC
:::
```

`standard` 指向基线 reaction。attempt 内省略的 factor 继承 baseline。声明过的 outcome 必须在每个 attempt 中给出。

## Factor 与 Outcome

`factor:` 表示输入或控制变量。`outcome:` 表示测量输出，例如 `yield`、`conversion`、`ee` 或 purity。名称必须先声明、不能重复、不能互相重名，也不能使用 `standard`、`factor`、`outcome`、`attempt`、`reaction`、`result`、`note`、`notes` 等保留字段。

```md
factor: solvent | baseline=THF
factor: catalyst | baseline=Pd(PPh3)4
outcome: yield | baseline=68 %
outcome: ee | baseline=92 %
```

outcome 的 baseline 描述 standard result。若 Chemd 能推断 standard result，且声明的 baseline 与 result 字段冲突，校验会报错。

## Attempt

每个 `attempt:` 开启一次尝试。建议使用稳定 ID，因为 `@cv-solvent.mecn-40` 这类引用会按 attempt ID 解析。

```md
attempt: dmf-60
reaction: @rxn-dmf-60
result: @res-dmf-60
solvent: DMF
temperature: 60 C
yield: 45 %
conversion: 70 %
```

`result:` 可省略；如果写出，必须引用 result block。attempt outcome 值不能和 linked result 的同名字段冲突。

## 组织 Reaction 与 Result

baseline reaction 和 attempt reaction 都应声明为普通 `:::chemd` reaction。较完整的结果数据写入 `:::result`，再由 attempt 的 `result:` 引用。

```md
:::result #res-mecn-40
reaction: @rxn-mecn-40
product: @product
status: success
yield: 72 %
conversion: 90 %
:::

:::condition-varies #cv-oxidation
standard: @rxn-baseline
factor: solvent | baseline=THF
outcome: yield | baseline=68 %

attempt: mecn-40
reaction: @rxn-mecn-40
result: @res-mecn-40
solvent: MeCN
yield: 72 %
:::
```

这样筛选表保持紧凑，同时 reaction、result 对象仍可用于图谱、导出和校验。

## 诊断

Chemd 会把影响含义、存在歧义或可能漏内容的条件筛选数据作为 error。重复声明、保留字段名、attempt 后继续声明 factor/outcome、缺失 attempt ID、未声明的 attempt 字段、重复 attempt 值、缺失 outcome、以及与 linked result 冲突都会报错。
