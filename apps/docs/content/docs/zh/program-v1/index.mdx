Chemd program v1 是 program-first 实验语言。一个 `.chemd` 文件就是一个
module。Program declarations 是语义事实来源。Markdown 只在 `///` doc
comments 或 `/*md */` 区域中作为文档存在。

本节是当前 program-first contract。Runtime packages、renderers、exports、
storage、language service、Desktop IDE 和 docs 均应对齐这些契约。
