---
title: '`:::batch` 块'
description: '`:::batch` 记录实验生成、分装、纯化或衍生得到的物理批次。'
---

`:::batch` 表示实验中生成或衍生出的物理批次。它不同于 `:::sample`；sample 表示取样/分析对象。

```md
:::batch #batch-crude-var1
source: @rxn-var1
molecule: @mol-product
state: crude
mass: 120 mg
purity: 84 %
:::
```

| 字段 | 必填 | 语义 |
| --- | --- | --- |
| `source` | 是 | reaction、result、sample 或 batch 引用 |
| `molecule` | 否 | molecule 引用 |
| `state` | 否 | `crude`、`purified` 等批次状态 |
| `mass` | 否 | mass 数量 |
| `purity` | 否 | percent 数量 |
| `artifacts` | 否 | artifact 引用列表 |
| `notes` | 否 | 备注 |
| `chemistry_features` | 否 | `|` 或 `,` 分隔的 feature ID |

sample 可通过 `ref` 指向 batch：

```md
:::sample #sample-nmr-var1
ref: @batch-crude-var1
artifacts: @art-nmr-var1
:::
```
