---
title: '`:::sample` 样品块'
description: '`:::sample` 记录样品名称、批次、纯度、来源关系、等分关系和附件引用。'
---

`:::sample` 生成 `sample` 节点，并参与样品谱系和证据链导出。

## 语法

```md
:::sample #sample-product
name: purified product
sample_id: P-2026-0519-01
batch: B1
purity: 98 %
derived_from: rxn-main
artifacts: art-nmr-product | art-hplc-product
:::
```

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | resolver 必填 |
| `sample_id` | 否 | 实验室样品编号 |
| `batch` | 否 | 批次 |
| `purity` | 否 | 纯度 |
| `supplier` | 否 | 供应商 |
| `notes` | 否 | 备注 |
| `ref` | 否 | 通用关联目标 |
| `derived_from` | 否 | 来源对象，可为 reaction、molecule、result 或 sample |
| `aliquot_of` | 否 | 等分来源 sample |
| `batch_of` | 否 | 批次来源 sample |
| `artifacts` | 否 | artifact ID 列表，支持 `|` 和 `,` |
| `chemistry_features` | 否 | feature ID 列表 |

## 必填与默认值

resolver 要求 `name`。parser 不设置默认值。省略 ID 时由 resolver 生成默认 sample ID。

## 推荐实践案例

样品追踪应区分 reaction 来源、批次样品和 aliquot。附件通过 `artifacts` 连接。

```md
:::sample #sample-crude
name: crude reaction mixture
derived_from: rxn-main
batch: crude-batch-01
notes: collected before purification
:::

:::sample #sample-purified
name: purified product
sample_id: P-01
batch_of: sample-crude
purity: 98 %
artifacts: art-nmr-product | art-hplc-product
:::

:::sample #sample-aliquot
name: NMR aliquot
aliquot_of: sample-purified
artifacts: art-nmr-product
:::
```

## 诊断

| 诊断码 | 条件 |
| --- | --- |
| `E_INVALID_ID` | sample ID 非法 |
| `W_UNKNOWN_FIELD` | 未声明字段 |
| `E_MISSING_REQUIRED_FIELD` | 缺少 `name` |
| `E_TYPED_REFERENCE_MISMATCH` | 关联关系指向不匹配对象 |
