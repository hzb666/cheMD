---
title: '`:::material` 块'
description: '`:::material` 记录库存物料、试剂瓶、供应商 lot 和纯度等信息。'
---

`:::material` 表示物理物料或试剂 lot。它必须引用其对应的 molecule 身份。

```md
:::material #mat-aryl-bromide-lot-a
molecule: @mol-aryl-bromide
supplier: Sigma
lot: A123
purity: 98%
density: 1.49 g/mL
storage: flammable cabinet
:::
```

| 字段 | 必填 | 语义 |
| --- | --- | --- |
| `molecule` | 是 | molecule 引用 |
| `supplier` | 否 | 供应商 |
| `lot` | 否 | 供应商或库存 lot |
| `purity` | 否 | percent 数量 |
| `density` | 否 | density 原文 |
| `storage` | 否 | 储存条件 |
| `notes` | 否 | 备注 |
| `chemistry_features` | 否 | `|` 或 `,` 分隔的 feature ID |

reaction participant 可直接引用 material：

```md
reactant: @mat-aryl-bromide-lot-a | 1.0 mmol | 1.0 eq | limiting=true
```
