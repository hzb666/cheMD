---
title: '`:::artifact` 附件块'
description: '`:::artifact` 记录谱图、图片、原始数据文件和其他证据附件。'
---

`:::artifact` 用于把文件证据连接到 reaction、result、analysis 或 sample。

## 语法

```md
:::artifact #art-nmr-product
kind: nmr_spectrum
ref: @sample-product
path: data/nmr/product-1h.pdf
checksum: sha256:abc123
instrument: Bruker 400
notes: 1H NMR spectrum for purified product
:::
```

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `kind` | 是 | 附件类型 |
| `ref` | 否 | 支持对象引用 |
| `path` | 是 | 文件路径 |
| `checksum` | 否 | 校验值 |
| `instrument` | 否 | 采集仪器 |
| `notes` | 否 | 说明 |
| `chemistry_features` | 否 | feature ID 列表 |

## 必填与默认值

resolver 要求 `kind` 和 `path`。parser 不设置默认值。

## 推荐实践案例

附件应使用稳定 ID，`kind` 表达文件角色，`ref` 指向最直接的证据对象。

```md
:::artifact #art-hplc-product
kind: hplc_chromatogram
ref: @res-main
path: data/hplc/product-purity.pdf
checksum: sha256:9d5e
instrument: Agilent 1260
notes: purity trace for isolated product
:::
```

## 诊断

| 诊断码 | 条件 |
| --- | --- |
| `E_INVALID_ID` | artifact ID 非法 |
| `W_UNKNOWN_FIELD` | 未声明字段 |
| `E_MISSING_REQUIRED_FIELD` | 缺少 `kind` 或 `path` |
| `E_TYPED_REFERENCE_MISMATCH` | `ref` 关系目标类型不符合规则 |
