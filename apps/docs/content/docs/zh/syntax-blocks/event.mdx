---
title: '`:::event` 与 `event:` 观察事件语法'
description: '`event` 是 `observation` 内部子语法，支持类型、阶段、时间点、严重程度、步骤关联、证据和置信度。'
---

`event` 只能写在 `:::observation` 内部。当前 typechecker 支持的事件类型为 `color_change`、`precipitation`、`gas_evolution` 和 `phase_change`。

## 两种写法

```md
event: color_change | id=e-color | color=yellow | linkedStep=s-heat
```

```md
:::event #e-phase
type: phase_change
stage: extraction
value: clear phase separation
linkedStep: s-extract
:::
```

## 结构字段

| 字段 | 说明 |
| --- | --- |
| `id` / `event_id` | event ID；嵌套块也可从 `#id` 读取 |
| `type` / `eventType` / `event_type` | 事件类型 |
| `stage` | 阶段 |
| `timepoint` | 时间点 |
| `severity` | 严重程度 |
| `linked_step` / `linkedStep` | 关联 step ID |
| `evidence` | 证据 ID 列表，使用 `,` 分隔 |
| `confidence` | 可解析数字 |

其他字段进入 `params`。`value`、`color` 或 `state` 会作为 normalized value 候选。

嵌套 `:::event` 可以从 `#id` 或裸 header 值读取 ID。未提供 ID 时，parser 会生成 `<observation-id>:eN`。

```md
:::observation #obs-main
:::event e-color
type: color_change
color: orange
:::

:::event
type: gas_evolution
severity: low
:::
:::
```

## 推荐实践案例

```md
:::event #e-color
type: color_change
stage: reaction
timepoint: 5 min after addition
severity: medium
color: orange to red
linkedStep: s-add
evidence: photo-color-1
confidence: 0.85
:::
```
