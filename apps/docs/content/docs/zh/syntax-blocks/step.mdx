---
title: '`:::step` 与 `step:` 步骤语法'
description: '`step` 是 `procedure` 内部子语法，支持 family、结构字段、参数、依赖、证据和置信度。'
---

`step` 不在顶层 block registry 中。它由 `procedure` 解析器识别，只能位于 `:::procedure` 内。

## 两种写法

```md
step: heat | id=s-heat | temperature=65 C | duration=4 h
```

```md
:::step #s-heat
family: heat
temperature: 65 C
duration: 4 h
:::
```

## 结构字段

| 字段 | 说明 |
| --- | --- |
| `id` / `step_id` | step ID；嵌套块也可从 `#id` 读取 |
| `family` | 步骤类型 |
| `inputs` | `,` 或 `|` 分隔的输入列表 |
| `outputs` | `,` 或 `|` 分隔的输出列表 |
| `depends_on` / `dependsOn` | 依赖 step ID 列表 |
| `stage` | 阶段 |
| `purpose` | 目的 |
| `evidence` | 证据 ID 列表 |
| `confidence` | 可解析数字 |

其他 `key=value` 或字段行会进入 `params`。数量字段包括 `amount`、`mass`、`volume`、`temperature`、`target_temperature`、`duration`、`time`、`pressure`、`concentration`、`equivalent`、`equivalents` 和 `percent`。

嵌套 `:::step` 可以从 `#id` 或裸 header 值读取 ID。未提供 ID 时，parser 会生成 `<procedure-id>:sN`。

```md
:::procedure #proc-main
:::step s-charge
family: charge
inputs: @mol-substrate
:::

:::step
family: heat
temperature: 65 C
:::
:::
```

## family

当前 typechecker 支持以下 family：

`charge`、`add`、`transfer`、`mix`、`cool`、`heat`、`hold`、`purge`、`quench`、`extract`、`wash`、`separate_layers`、`filter`、`dry`、`concentrate`、`purify`、`sample`、`analyze`、`observe`、`store`。

`purge` 会在缺少 `atmosphere` 时补默认值 `nitrogen`。`heat` 需要 `temperature`、`target_temperature` 或 `duration` 之一。`cool` 需要 `temperature`、`target_temperature` 或 `method` 之一。`analyze` 需要 `analysisType`、`analysis_type` 或 `type` 之一。`extract` 需要 `solvent`。`filter` 只允许 `medium` 和 `wash` 参数。

## 推荐实践案例

```md
:::step #s-extract
family: extract
stage: workup
dependsOn: s-quench
inputs: crude-mixture
outputs: organic-layer
solvent: ethyl acetate
volume: 20 mL
evidence: notebook-p14
confidence: 0.9
:::
```

```md
step: analyze | id=s-tlc | analysisType=tlc | dependsOn=s-heat | evidence=ana-tlc-main
```
