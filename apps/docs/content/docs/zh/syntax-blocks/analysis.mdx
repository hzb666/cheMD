`:::analysis` 记录分析证据。必填字段是 `type`；不同 `type` 决定允许的结构化字段和诊断边界。

## 字段

| 字段 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | 是 | 无 | `tlc`、`nmr`、`hplc`、`uplc`、`gc`、`lcms`、`gcms`、`ms`、`hrms`、`ir`、`uv`；别名：`analysis_type`、`analysisType` |
| `ref` | 否 | 无 | 指向 sample、reaction、result、condition screen 或 attempt |
| `time` | 否 | 无 | 采样或分析时间；TLC 归一化接受 `h`、`hr`、`hrs`、`min`、`mins` |
| `eluent` | 否 | 无 | TLC 展开剂 |
| `plate` | 否 | `type: tlc` 时为 `silica gel GF254` | TLC 板材 |
| `visualization` | 否 | `type: tlc` 时为 `UV 254 nm` | TLC 显色/观察方式 |
| `result` | 否 | 无 | 关联 result id 或简短解释 |
| `instrument` | 否 | 无 | 仪器名称 |
| `solvent` | 否 | 无 | NMR 溶剂或方法溶剂 |
| `frequency` | 否 | 无 | 未写在 `spectrum` 中的 NMR 频率 |
| `method` | 否 | 无 | method/profile 引用或方法名称 |
| `artifact` | 否 | 无 | 可重复的原始数据 artifact 引用；别名 `artifacts` 接受 `|` 列表 |
| `spectrum` | 否 | 无 | NMR 谱图级元数据 |
| `lane` | 否 | 无 | TLC 结构化泳道；每条 lane 重复一次 |
| `spot` | 否 | 无 | 当前 `lane` 下的 TLC 点 |
| `mess` | 否 | 无 | 当前 `lane` 下的拖尾、糊斑或宽区域 |
| `base` | 否 | 无 | 标记当前 TLC lane 的基线；也可带点位内容 |
| `none` | 否 | 无 | 标记当前 TLC lane 为空 |
| `peak` | 否 | 无 | 可重复的 NMR/色谱峰 |
| `ion` | 否 | 无 | 可重复的 MS ion |
| `data` | 否 | 无 | 无类型化字段时的非结构化兜底 |
| `notes` | 否 | 无 | 备注 |
| `p1`、`p2`、... | 否 | 无 | 旧式紧凑 TLC lane 字段 |

## TLC

```md
:::analysis #ana-tlc
type: tlc
ref: @sample-crude
method: @tlc-method-pe-ea-5-1

lane: sm | source=@mat-aryl
spot: 0.62

lane: rxn | source=@sample-crude
spot: sm
spot: 0.31 ^3(4) prod
mess: 0.55 (3)

lane: prod | source=@sample-product
spot: 0.30
:::
```

`lane:` 开启一条 lane。后续 `spot`、`mess`、`base`、`none` 都归属当前 lane，直到下一个 `lane:`。lane label 和 spot label 必须是内置 role 或对象引用。内置 role 包括 `sm`、`rxn`、`prod`、`int`、`blank`、`impurity`、`unknown` / `unk`。

`spot: sm` 引用已知标准 spot，不是引用整条 lane。它只复用该 spot 的 Rf 和 marker 等点位事实，不继承 lane 参数。没有候选、候选不唯一或目标冲突都会报错。`unknown` 只能和 Rf 一起使用，例如 `spot: 0.42 unknown`。

### TLC 点位 marker

TLC 点位写作：

```md
spot: <rf> [marker] [label-or-reference]
```

`marker` 可省略。它同时表达形状、大小和深浅：

| marker 部分 | 写法 | 归一化含义 |
| --- | --- | --- |
| 形状 | 省略、`^`、`v` | 省略为 `circle`；`^` 为 `up`；`v` 为 `down` |
| 大小 | 形状后写 `1` 到 `5` | `size_rank`；超出范围会夹到 `1..5` |
| 深浅 | 大小或形状后写 `(1)` 到 `(5)` | `intensity_rank`；超出范围会夹到 `1..5` |

示例：

```md
spot: 0.31 ^3(4) product
spot: 0.62 v2 @mol-starting-material
mess: 0.55 3(2)
```

`^3(4)` 表示向上的点，大小 rank 为 `3`，深浅 rank 为 `4`。普通 `spot: 0.30` 是圆点，不带大小和深浅 rank。

## NMR

```md
:::analysis #ana-nmr
type: nmr
ref: @sample-purified
spectrum: 1H NMR (400 MHz, CDCl3)
peak: 7.68-7.59 (m, 2H, ArCH)
peak: 3.56 (tt, J = 9.1, 6.0 Hz, 1H, CH(C=O))
artifact: @art-nmr
:::
```

`spectrum:` 提供谱图级元数据。`peak:` 使用常见文献格式：`化学位移或范围 (形状, 耦合常数?, 积分?, 归属?)`。缺省项保留为空；无法解析化学位移是 error。

## 色谱与质谱

```md
:::analysis #ana-lcms
type: lcms
method: @lcms-esi-pos
peak: 6.4 min (97 %, product)
ion: m/z 124.1 ([M+H]+, product)
:::
```

HPLC/UPLC/GC 的 `peak:` 使用 `retention-time (area %, component)`。LCMS 和 GCMS 可同时写 `peak:` 与 `ion:`。MS/HRMS 使用 `ion:`。LCMS 只有 peak 没有 ion 会报错，因为会丢失质谱含义。

## 诊断

| 诊断码 | 条件 |
| --- | --- |
| `E_TLC_LANE_REQUIRED` | `spot`、`mess`、`base` 或 `none` 出现在 `lane` 之前 |
| `E_TLC_LABEL_UNKNOWN` | TLC lane 或 spot label 不是 role 或引用 |
| `E_TLC_SPOT_REFERENCE` | label-only spot 无法解析到唯一标准 spot |
| `E_TLC_UNKNOWN_REFERENCE` | `spot: unknown` 没有 Rf，也没有确定身份 |
| `E_TLC_SPOT_LABEL_REQUIRED` | 混合或自定义 lane 的 spot 缺少 label |
| `E_ANALYSIS_FIELD_FOR_TYPE` | 字段不适用于当前 analysis type |
| `E_ANALYSIS_SPECTRUM_CONFLICT` | NMR spectrum 与显式字段冲突 |
| `E_ANALYSIS_PEAK_SYNTAX` | peak 缺少必要化学位移或保留时间 |
| `E_ANALYSIS_ION_REQUIRED` | LCMS peak 缺少 ion |
| `E_ANALYSIS_ION_SYNTAX` | ion 缺少 m/z |
