## 块清单

| 块 | 作用 | 主要输出节点 |
| --- | --- | --- |
| `:::chemd` | 分子与反应对象 | `molecule` 或 `reaction` |
| `:::material` | 库存物料或试剂 lot | `material` |
| `:::batch` | 实验生成或纯化得到的物理批次 | `batch` |
| `:::result` | 实验结果 | `result` |
| `:::analysis` | 分析记录 | `analysis` |
| `:::procedure` | 实验过程 | `procedure` |
| `:::step` | `procedure` 内部步骤 | `step` |
| `:::observation` | 观察记录 | `observation` |
| `:::trace` | 运行 trace 记录 | `trace` |
| `:::event` | `observation` 内部事件 | `event` |
| `:::sample` | 样品记录 | `sample` |
| `:::artifact` | 文件、谱图、图片等附件 | `artifact` |
| `:::condition-varies` | 条件筛选与变量变化 | `condition_varies` |
| `:::template` | 可复用模板 | `template` |
| `:::use` | 模板调用 | `use` |
| `:::col` | 多列布局 | `col` |

## 块字段参考

下表列出每一种块当前接受的字段。`必填` 表示 resolver 或 typechecker 在缺少该字段或等价语义输入时会报错。

| 块 | 字段 | 必填 | 默认值 |
| --- | --- | --- | --- |
| `:::chemd` | `kind`、`smiles`、`cas`、`inchi`、`inchikey`、`canonical_smiles`、`name`、`role`、`caption`、`formula`、`mw`、`amount`、`equivalents`、`reactant`、`product`、`conditions`、`route`、`prev`、`equation`、`rxn_smiles`、`reagents`、`catalyst`、`solvent`、`temperature`、`time`、`pressure`、`atmosphere`、`yield`、`conversion`、`selectivity`、`chemistry_features` | reaction 节点需要 `reactant` 和 `product`；molecule 节点在 typecheck 时需要至少一个身份字段 | 字段形状明确时可推断 `kind`；省略对象 ID 时会生成 |
| `:::material` | `molecule`、`supplier`、`lot`、`purity`、`density`、`storage`、`notes`、`chemistry_features` | `molecule` | 省略对象 ID 时会生成 |
| `:::batch` | `source`、`molecule`、`state`、`mass`、`purity`、`notes`、`artifacts`、`chemistry_features` | `source` | 省略对象 ID 时会生成 |
| `:::result` | `status`、`yield`、`conversion`、`selectivity`、`isolated_mass`、`product_state`、`purity`、`notes`、`ref`、`reaction`、`product` | 无 | 省略对象 ID 时会生成 |
| `:::analysis` | `type`、`ref`、`time`、`eluent`、`plate`、`visualization`、`result`、`instrument`、`solvent`、`frequency`、`method`、`artifact`、`spectrum`、`lane`、`spot`、`mess`、`base`、`none`、`peak`、`ion`、`data`、`notes`、`pN` | `type` | TLC 默认 `plate` 为 `silica gel GF254`，`visualization` 为 `UV 254 nm`；省略对象 ID 时会生成 |
| `:::procedure` | `ref`、`reaction`、`evidence`；子行 `step`、`repeat`、`until`、`branch`、`parallel`、`wait`、`abort_if` | 块级无必填 | 省略对象 ID 和匿名 step ID 时会生成 |
| `:::step` | `id`、`step_id`、`family`、`inputs`、`outputs`、`depends_on`、`stage`、`purpose`、`evidence`、`confidence`；其他字段进入 params | 嵌套块形式需要 `family`；部分 family 需要特定参数 | 匿名 step 得到 `<procedure-id>:sN`；`purge` 默认补 `atmosphere: nitrogen` |
| `:::observation` | `ref`；子行 `event` | 无 | 省略对象 ID 时会生成；匿名 event 得到 `<observation-id>:eN` |
| `:::event` | `id`、`event_id`、`type`、`stage`、`timepoint`、`severity`、`linked_step`、`evidence`、`confidence`；其他字段进入 params | 嵌套块形式需要 `type` | 省略 event ID 时会生成 |
| `:::trace` | `plan`、`mode`；子行 `event` | trace typecheck 需要 `plan` | 省略对象 ID 时会生成 |
| `:::sample` | `name`、`sample_id`、`batch`、`purity`、`supplier`、`notes`、`ref`、`derived_from`、`aliquot_of`、`batch_of`、`artifacts`、`chemistry_features` | `name` | 省略对象 ID 时会生成 |
| `:::artifact` | `kind`、`ref`、`path`、`checksum`、`instrument`、`notes`、`chemistry_features` | `kind`、`path` | 省略对象 ID 时会生成 |
| `:::condition-varies` | `reaction`、`standard`、`factor`、`outcome`、`attempt`、`notes` | 块级无必填；每个 `attempt` 需要 id | 省略对象 ID 时会生成 |
| `:::template` | `params`、`bind`、`description`、`body` | 块头 template 名称 | 无 |
| `:::use` | 任意模板参数字段 | 块头目标 template 名称；必填参数由 template 定义决定 | 列表值会合并为 ` | ` |
| `:::col` | `columns`、`col:` 子项 | 无 | 非法列数回退为 `1` |

## 通用规则

块头使用 `:::block-name`。对象块 ID 写在块头参数中，格式为 `#id`。ID 必须匹配 `[a-zA-Z][a-zA-Z0-9_-]*`。字段写作 `key: value`，字段名必须以小写字母开头，后续允许小写字母、数字和下划线。同一行可使用 `;;` 写多个字段。

```md
:::result #res-main
status: success ;; yield: 82% ;; purity: 96%
:::
```

列表字段按块定义处理。通用列表字段包含 `reactants`、`products`、`reactant`、`product`、`reac`、`prod`、`conditions` 和 `params`。空列表项产生 `E_INVALID_LIST_ITEM`。

## 推荐组织方式

一份实验记录通常按对象依赖顺序编写：先声明 molecule，再声明 reaction，随后记录 procedure、observation、analysis、result、sample 和 artifact。条件筛选记录以 standard reaction 和 variation reaction 为中心组织。

```md validate
---
id: exp-user-guide
title: User guide example
date: 2026-05-19
primary_reaction: rxn-main
primary_result: res-main
---

:::chemd #mol-substrate
name: substrate
smiles: CCO
:::

:::chemd #mol-product
name: product
smiles: CC=O
:::

:::chemd #rxn-main
reactant: @mol-substrate | 1.00 mmol | 1.0 eq | limiting=true
product: @mol-product
solvent: MeCN
temperature: 60 C
time: 3 h
:::

:::result #res-main
reaction: @rxn-main
product: @mol-product
status: success
yield: 74%
:::
```
