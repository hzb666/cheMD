---
title: '`:::chemd` 分子与反应块'
description: '`:::chemd` 声明 molecule 身份与 reaction；material 和 batch 表达物理物料与批次来源。'
---

`:::chemd` 根据 `kind` 和字段形状生成 `molecule` 或 `reaction` 节点。字段形状明确时可以省略 `kind`。`mol` 和 `reac` 是 `kind` 的值别名。

## Molecule 身份

molecule 只表达化学身份。不要把本次反应用量、当量或投料量写在 molecule 上；这些数量写在 reaction participant 上。

```md
:::chemd #mol-substrate
kind: molecule
name: ethyl acetate
smiles: CCOC(C)=O
formula: C4H8O2
mw: 88.11 g/mol
:::
```

身份字段包括 `name`、`smiles`、`canonical_smiles`、`cas`、`inchi`、`inchikey`、`formula`、`mw`、`role`、`caption` 和 `chemistry_features`。typechecker 要求 molecule 至少具备一个身份字段。`inchi` 必须以 `InChI=` 开头，`inchikey` 必须是标准大写 14-10-1 分段格式。molecule 上的 `amount` 和 `equivalents` 会产生 error。

## Reaction Participant

reaction 使用单数 canonical 字段表达参与物。`reactant` 和 `product` 可重复。`reac` 和 `prod` 是短别名。复数字段 `reactants` 和 `products` 只作为简单列表别名；不要在其中写 amount、equiv 或 `limiting=true`。

```md
:::chemd #rxn-main
kind: reaction
reactant: @mat-substrate-lot-a | 1.00 mmol | 1.0 eq | limiting=true
reactant: @mol-base | equiv=1.2
product: @mol-product
rxn_smiles: CCO.N>>CCN
solvent: MeCN
temperature: r.t. -> 60 C over 30 min
time: overnight
atmosphere: nitrogen
:::
```

participant 可引用 `molecule`、`material` 或 `batch`。amount 可写 `amount=1.0 mmol`，也可省成 `1.0 mmol`。equivalent 可写 `equiv=1.2`、`equiv=1.2 eq` 或 `1.2 eq`。只要任一 reactant 写了 amount、equivalent、mass、volume 或 `limiting=true`，就必须且只能有一个 `limiting=true`。limiting reactant 必须同时有 amount 和 equivalent。其他有化学计量语义的 reactant 至少有 amount 或 equivalent。product participant 不能写 expected 或 isolated 数量；结果数据写在 `:::result`。

## Material 与 Batch

`:::material` 表示购买或库存物料。`:::batch` 表示实验中生成、分装、纯化或得到的一批物理样品。

```md
:::material #mat-substrate-lot-a
molecule: @mol-substrate
supplier: Sigma
lot: A123
purity: 98 %
storage: flammable cabinet
:::

:::batch #batch-crude
source: @rxn-main
molecule: @mol-product
state: crude
mass: 120 mg
purity: 84 %
:::
```

`material.molecule` 必须引用 molecule。`batch.source` 可引用 reaction、result、sample 或 batch。`batch.molecule` 可引用 molecule。sample 的 `ref` 可指向 material、batch、reaction、result、sample 或其他对象。

## 字段

| 字段 | molecule | reaction | 说明 |
| --- | --- | --- | --- |
| `kind` | 可选 | 可选 | `molecule`、`reaction`、`mol`、`reac`；字段明确时可推断 |
| `name` | 可选 | 可选 | 使用者可读名称 |
| `smiles` | 可选 | 不适用 | molecule 身份 |
| `canonical_smiles` | 可选 | 不适用 | canonical 结构字符串 |
| `cas` | 可选 | 不适用 | CAS registry string |
| `inchi` / `inchikey` | 可选 | 不适用 | molecule 身份 |
| `formula` | 可选 | 不适用 | 分子式原文 |
| `mw` | 可选 | 不适用 | 分子量文本 |
| `reactant` / `reac` | 不适用 | 可重复 | 结构化 participant |
| `product` / `prod` | 不适用 | 可重复 | 结构化 participant |
| `reactants` / `products` | 不适用 | 可选别名 | 仅简单引用/文本列表 |
| `conditions` | 不适用 | 可选 | 字符串列表 |
| `route` | 不适用 | 可选 | 路线 ID 或标签 |
| `prev` | 不适用 | 可选 | 前驱 reaction 引用列表 |
| `reagents` / `catalyst` / `solvent` | 不适用 | 可选 | 原文条件字段 |
| `temperature` / `time` / `pressure` | 不适用 | 可选 | 类型化数量 |
| `atmosphere` | 不适用 | 可选 | `nitrogen`、`argon`、`air`、`oxygen`、`inert` 或扩展值 |
| `yield` / `conversion` / `selectivity` | 不适用 | 可选 | reaction 级结果提示；result 仍是权威结果 |
| `equation` / `rxn_smiles` | 不适用 | 可选 | reaction 身份字符串；`reaction_smiles` 是 `rxn_smiles` 的别名 |
| `chemistry_features` | 可选 | 可选 | `|` 或 `,` 分隔的 feature ID |

## 类型推断

parser 通过 participant 字段和 reaction-only 字段推断 reaction，例如 `reactant`、`product`、`rxn_smiles`、`reaction_smiles`、`solvent`、`temperature`、`time`、`yield` 或 `conversion`。通过 `smiles`、`cas`、`inchi`、`inchikey`、`canonical_smiles`、`formula` 或 `mw` 等身份字段推断 molecule。推断不稳定、显式 `kind` 非法或字段形状冲突时都是 error。

## 数量表面语法

带单位数量必须在数字和单位之间保留空格：`78 %`、`1.0 mmol`、`1.0 eq`、`30 min`。`78%` 这样的紧凑写法是 error。`1 ml` 这类大小写不规范会被接受并归一为 `1 mL`，同时产生 warning。

## 诊断

| 诊断码 | 条件 |
| --- | --- |
| `E_INVALID_ID` | block ID 非法 |
| `W_UNKNOWN_FIELD` | 未声明字段 |
| `E_INVALID_LIST_ITEM` | 列表字段出现空项 |
| `E_CHEMD_KIND_CONFLICT` | `kind` 非法，或显式类型与字段形状冲突 |
| `E_MOLECULE_IDENTITY_MISSING` | molecule 没有身份字段 |
| `E_MOLECULE_REACTION_QUANTITY` | molecule 写了反应用量 |
| `E_INTEROP_SMILES_PARSE` | SMILES 身份字段不是可解析的单 token |
| `E_INTEROP_INCHI_FORMAT` | InChI 身份字段没有以 `InChI=` 开头 |
| `E_INTEROP_INCHIKEY_FORMAT` | InChIKey 身份字段不是标准分段格式 |
| `E_INTEROP_RXN_SMILES_PARSE` | reaction structure 字段不是有效 RXN SMILES 表面 |
| `E_REACTION_PARTICIPANT_SYNTAX` | 在复数列表别名上写了结构化 participant 事实 |
| `E_TYPED_REFERENCE_MISMATCH` | 引用目标类型错误 |
| `E_STOICHIOMETRY_LIMITING` | limiting reactant 规则被破坏 |
| `E_STOICHIOMETRY_QUANTITY_MISSING` | participant 缺少必要 amount/equivalent |
