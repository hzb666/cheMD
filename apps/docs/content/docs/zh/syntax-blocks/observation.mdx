---
title: '`:::observation` 观察块'
description: '`:::observation` 记录实验观察正文，并可包含结构化 event。'
---

`:::observation` 支持自由正文、行内 `event:` 和嵌套 `:::event`。

## 语法

```md
:::observation #obs-main
ref: @rxn-main
event: color_change | id=e-color | color=deep red | linkedStep=s-add | confidence=0.8
The mixture turned deep red after n-BuLi addition.
:::
```

## 字段

| 字段 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ref` | 否 | 无 | 观察目标引用 |
| `event:` 子行 | 否 | 无 | 在当前 observation 内创建结构化 event |
| 嵌套 `:::event` | 否 | 无 | 在当前 observation 内创建结构化 event 块 |

`observation` 没有 resolver 必填字段。若未写显式 event，typechecker 会把正文交给 step ontology lowering 生成观察事件。

## 结构化事件

事件支持行内 `event:` 和嵌套 `:::event`。显式事件会进入 `events`，并保留正文到 `body`。

```md
:::observation #obs-workup
ref: @rxn-main

:::event #e-precipitate
type: precipitation
stage: workup
timepoint: after water addition
value: white solid
linkedStep: s-quench
evidence: photo-workup
confidence: 0.9
:::

A white solid appeared after water addition.
:::
```

嵌套 event header 也接受裸 ID，例如 `:::event e-color`。如果 header 与字段都没有提供 ID，parser 会生成 `<observation-id>:eN`。

### Event 字段

| 字段 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `id` | 否 | 省略时为 `<observation-id>:eN` | event ID；别名：`event_id` |
| `type` | 是 | 无 | event 类型；别名：`eventType`、`event_type` |
| `stage` | 否 | 无 | 实验阶段 |
| `timepoint` | 否 | 无 | 时间点或相对步骤位置 |
| `severity` | 否 | 无 | 定性严重程度 |
| `linked_step` | 否 | 无 | 关联 step ID；别名：`linkedStep` |
| `evidence` | 否 | 无 | 逗号分隔的 evidence ID |
| `confidence` | 否 | 无 | 数值置信度 |
| 其他字段 | 否 | 无 | 存入 event `params`；`value`、`color` 或 `state` 可成为归一化值候选 |

行内 event 默认把第一个片段作为类型；也可以显式写成 `type=...`：

```md
event: color_change | id=e-color | color=orange | linkedStep=s-add
event: type=phase_change | id=e-phase | value=clear upper layer
```

## 诊断

| 诊断码 | 条件 |
| --- | --- |
| `E_INVALID_ID` | observation ID 非法 |
| `W_UNKNOWN_FIELD` | 顶部字段不在 `ref` 内 |
| `E_OBSERVATION_EVENT_INVALID_TYPE` | event type 不在支持集合 |
| `E_OBSERVATION_LINKED_STEP_MISSING` | `linkedStep` 指向缺失 step |

## 推荐实践案例

观察记录应把可结构化的变化写成 event，把叙述细节保留在正文。

```md
:::observation #obs-main
ref: @rxn-main
event: color_change | id=e-color | stage=reaction | timepoint=after addition | color=orange | linkedStep=s-add | evidence=photo-1
event: gas_evolution | id=e-gas | severity=low | linkedStep=s-quench
Mixture became orange after addition. Mild bubbling occurred during quench.
:::
```
