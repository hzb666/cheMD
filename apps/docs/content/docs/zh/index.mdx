## 导航模型

| 目标 | 阅读内容 |
| --- | --- |
| 写出第一份可验证源文件 | 入门，然后阅读语言基础 |
| 查询块字段或默认值 | 结构化块参考 |
| 建模真实实验记录 | 实验记录建模 |
| 使用模板、引用、表达式、布局或工作区语义 | 高级语言特性 |
| 校验、导出、fix 或查看诊断 | 验证、诊断与工具链 |
| 扩展实现或集成工具 | 代码库导览 |

语言章节构成主要阅读路径。代码库导览是独立的实现路径，适合在语言行为清晰后阅读。

## 最小文档

```md
---
id: exp-one-step-esterification
title: Standard Fischer esterification
date: 2026-04-24
primary_reaction: rxn-main
primary_result: res-main
---

:::chemd #mol-acid
name: benzoic acid
smiles: O=C(O)c1ccccc1
role: substrate
:::

:::chemd #mol-alcohol
name: ethanol
smiles: CCO
role: coupling_partner
:::

:::chemd #mol-product
name: ethyl benzoate
smiles: CCOC(=O)c1ccccc1
role: product
:::

:::chemd #rxn-main
name: Fischer esterification
reactant: @mol-acid | 1.0 mmol | 1.0 eq | limiting=true
reactant: @mol-alcohol | 5.0 mL
product: @mol-product
catalyst: H2SO4
solvent: ethanol
temperature: 78 C
time: 4 h
:::

:::result #res-main
reaction: @rxn-main
product: @mol-product
status: success
yield: 76%
purity: 95%
:::
```

该示例覆盖 Chemd 的核心使用模型：记录级元数据、分子对象、反应对象、结果对象和主对象引用。
