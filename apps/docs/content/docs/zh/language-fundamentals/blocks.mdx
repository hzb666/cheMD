## 通用块语法

结构化块以 `:::block-type` 开始，以独立的 `:::` 结束。起始行可以带 header 参数，常见写法是对象 ID，例如 `#res-main`。

```md
:::result #res-main
status: success
yield: 76 %
:::
```

对象 ID 必须匹配 `[a-zA-Z][a-zA-Z0-9_-]*`。非法 ID 产生 `E_INVALID_ID`。无显式 ID 的节点会获得 `<document-id>-<node-type>-<counter>` 形式的生成 ID，但稳定引用应使用显式 ID。

字段行使用 `key: value`。字段 key 必须以小写字母开头，后续允许小写字母、数字和下划线。字段值会去除两端空白。

```md
solvent: MeCN ;; temperature: 40 C ;; time: 2 h
```

解析器也支持 `;;` 多字段行。每个片段会按字段解析，但 span 仍指向同一物理行。

列表字段使用 `|` 分隔。默认列表字段为 `reactant`、`product`、`reac`、`prod`、`reactants`、`products`、`conditions` 和 `params`；`:::chemd` 额外把 `prev` 作为列表字段。空列表项产生 `E_INVALID_LIST_ITEM`。

每个块解析器声明自己的允许字段集合。未知字段产生 error 级 `W_UNKNOWN_FIELD` 诊断，该字段不会写入解析节点。

每个规范字段也有共享 value category，供文档和工具层使用。当前类别包括普通
文本、enum、quantity、percent、reference 或 literal、list、record、化学标识符
以及领域专用紧凑语法。TLC `spot`、analysis `peak`、MS `ion` 等领域字段仍保留
作者写下的紧凑 record，后续由对应类型的 normalizer 解析。

## 支持的块

正文解析器当前支持以下结构化块形式。大多数条目来自 block parser registry；`:::template` 是 `parseChildren` 内部处理的特殊分支。

| 块 | AST 类型 | 用途 |
| --- | --- | --- |
| `:::chemd` | `molecule` 或 `reaction` | 分子和反应的统一使用者输入表面 |
| `:::material` | `material` | 购买或库存物料，关联 molecule |
| `:::batch` | `batch` | 实验中生成、分装或纯化得到的批次 |
| `:::result` | `result` | 结果、产率、纯度和状态 |
| `:::analysis` | `analysis` | TLC、NMR、HPLC 等分析记录 |
| `:::procedure` | `procedure` | 操作步骤和步骤依赖 |
| `:::trace` | `trace` | 运行或手写事件记录 |
| `:::observation` | `observation` | 观察事件 |
| `:::sample` | `sample` | 样品、批次和派生关系 |
| `:::artifact` | `artifact` | 文件、谱图、图片和外部证据 |
| `:::condition-varies` | `condition_varies` | 条件筛选和变量对比 |
| `:::template` | `template` | 可复用片段；parser 特殊分支 |
| `:::use` | `use` | 模板调用 |
| `:::col` | `col` | 多列布局节点 |

未知块产生 error 级 `W_UNKNOWN_BLOCK` 诊断。

## `:::chemd`

`:::chemd` 是分子和反应的统一块。`kind: molecule` 和 `kind: reaction` 仍然允许，也支持 `mol`、`reac` 等别名；但当字段已经能表达含义时可以省略。包含 `reactant`、`product`、`reac`、`prod`、`rxn_smiles`、`solvent` 或 `temperature` 等反应形字段时推断为 reaction。包含 `smiles`、`inchi`、`inchikey`、`cas`、`formula` 或 `role` 等分子身份字段时推断为 molecule。形状不明确或互相冲突时是 error。

```md
:::chemd #mol-aryl
name: aryl bromide
smiles: Brc1ccccc1
role: substrate
:::

:::chemd #rxn-main
name: Suzuki coupling
reactant: @mol-aryl | 1.0 mmol | 1.0 eq | limiting=true
reactant: @mol-boron | 1.2 eq
product: @mol-product
reagents: K3PO4
catalyst: Pd(PPh3)4
solvent: MeCN
temperature: 40 C
time: 2 h
atmosphere: nitrogen
:::
```

分子字段：`smiles`、`canonical_smiles`、`inchi`、`inchikey`、`cas`、`name`、`role`、`caption`、`formula`、`mw`、`chemistry_features`。

反应字段：`reactant`、`product`、`reac`、`prod`、`reactants`、`products`、`rxn_smiles`、`reaction_smiles`、`conditions`、`route`、`prev`、`reagents`、`catalyst`、`solvent`、`temperature`、`time`、`pressure`、`atmosphere`、`yield`、`conversion`、`selectivity`、`caption`、`chemistry_features`。

校验规则：

- molecule 至少需要一个身份字段。
- reaction 在别名归一化后至少需要一个 reactant 和一个 product。
- molecule 上的 `amount` 和 `equivalents` 是 error；反应用量应写到 reaction participant 上。

## `:::result`

结果块记录实验输出。`ref` 和 `reaction` 都可承载反应关联；同一份记录中建议保持写法一致。

```md
:::result #res-main
ref: @rxn-main
product: @mol-product
status: success
yield: 78 %
conversion: 96 %
selectivity: 93 %
purity: 97 %
notes: Best balance of conversion and purity.
:::
```

字段：`status`、`yield`、`conversion`、`selectivity`、`isolated_mass`、`product_state`、`purity`、`notes`、`ref`、`reaction`、`product`。

## `:::analysis`

分析块记录仪器或观察型分析。字段 `type` 会进入 AST 的 `type_name`。当 `type: tlc` 时，解析器为缺失的 `plate` 和 `visualization` 填入 TLC 默认值。

```md
:::analysis #ana-tlc-main
type: tlc
ref: @rxn-main
time: 2 h
eluent: PE/EA = 4:1
result: one major product spot with trace starting material
data: TLC plate after 2 h.
lane: sm
spot: 0.78 sm
lane: rxn
spot: 0.52 prod
spot: 0.79 sm
lane: prod
spot: 0.50 prod
:::
```

字段：`type`、`ref`、`time`、`eluent`、`plate`、`visualization`、`result`、`instrument`、`solvent`、`frequency`、`method`、`data`、`notes`、`artifact`、`artifacts`、`spectrum`、`lane`、`spot`、`mess`、`base`、`none`、`peak`、`ion`。

resolver 必填校验：

- analysis 需要 `type`。
- TLC analysis 的 `plate` 和 `visualization` 可由默认值补齐。

## `:::sample`

样品块表达样品身份、来源和附件关系。

```md
:::sample #sample-product-var1
ref: @res-var1
name: purified product from var1
derived_from: sample-batch-var1
purity: 97 %
artifacts: art-nmr-var1
:::
```

字段：`name`、`sample_id`、`batch`、`purity`、`supplier`、`notes`、`ref`、`derived_from`、`aliquot_of`、`batch_of`、`artifacts`、`chemistry_features`。

resolver 必填校验：sample 需要 `name`。

## `:::artifact`

附件块表达谱图、图片、报告和其他证据文件。

```md
:::artifact #art-nmr-var1
kind: nmr_spectrum
ref: @res-var1
path: data/nmr/var1.pdf
checksum: sha256:var1nmr
instrument: Bruker 400
notes: Purified product spectrum.
:::
```

字段：`kind`、`ref`、`path`、`checksum`、`instrument`、`notes`、`chemistry_features`。

resolver 必填校验：artifact 需要 `kind` 和 `path`。
