## 普通 Markdown 段落

未被结构化块捕获的正文会生成 `MarkdownNode`。节点保存原始 `value`，并附带 `references`、`inlineChem`、`inlineCode` 和 `links` 四组 token。

```md
The reaction mixture stayed homogeneous for 30 min.
TLC showed full consumption of @mol-substrate.
```

## `@id` 对象引用

`@mol-main` 生成 `kind: "object"` 的引用 token。resolver 在对象索引中查找 `source` 对应的 ID。未找到对象时产生 `W_UNRESOLVED_REFERENCE`。

```md
The limiting reagent was @mol-substrate.
```

## `@id.field` 字段引用

`@res-main.yield` 生成 `kind: "object_field"`。resolver 先找到对象，再读取指定字段。`condition_varies` 节点还支持通过字段名读取 attempt。

```md
Isolated yield: @res-main.yield.
Attempt summary: @cv-screen.var1.
```

## `@reaction.field` 等 primary alias

`reaction`、`result`、`product`、`sample`、`molecule` 和 `analysis` 是 primary alias 名称。`@reaction.name` 会通过 `primary_reaction` 找到对象，再读取 `name` 字段。

```md
Primary reaction: @reaction.name.
Primary result yield: @result.yield.
```

## `@meta.field` 元数据引用

`@meta.title` 读取 frontmatter 中的 `title`。缺失字段产生未解析引用诊断。

```md
Record title: @meta.title.
Campaign: @meta.campaign.
```

## `@param.field` 模板参数引用

`@param.temperature` 在模板展开上下文内读取 `:::use` 传入值。模板 `bind` 中声明的别名不会按 param 处理。

```md
:::template heat-note
params: temperature: quantity<temperature> | duration: quantity<time>
Heating was held at @param.temperature for @param.duration.
:::

:::use heat-note
temperature: 65 C
duration: 4 h
:::
```

## `:chem[...]` 行内化学表达式

`:chem[CCO]` 生成 `InlineChemToken`。空值、跨行内容和缺少右括号的内容不会生成 token。

```md
The solvent was :chem[CCO], and the product SMILES was :chem[COc1ccc(-c2ccccc2)cc1].
```

行内代码使用反引号，生成 `InlineCodeToken`。空代码片段和跨行代码片段不会被 tokenizer 接收。

```md
反应形状清晰时直接写 `reactant:` 和 `product:`；`kind: reaction` 可以省略。
```

## Markdown 链接安全标记

Markdown 链接 token 包含 `safe`。安全 href 包括锚点、绝对路径、相对路径、无 scheme 文本，以及 `http`、`https`、`mailto`。控制字符和未允许 scheme 会产生 `W_UNSAFE_LINK_HREF`。

```md
[local method](./methods/suzuki.md)
[instrument record](https://example.test/instruments/hplc-01)
[unsafe](javascript:alert(1))
```

## 行内语法实现清单

reference token 的识别正则要求 ID 以字母开头，后续可包含字母、数字、下划线和中横线。字段名以字母开头，后续可包含字母、数字、下划线和中横线。该规则允许 Markdown 正文引用结构化块 ID，也允许字段名与 AST 字段保持一致。

primary alias 只覆盖 `reaction`、`result`、`product`、`sample`、`molecule` 和 `analysis`。这些名称在解析时会先作为 alias 处理。若需要引用同名普通对象，应使用更明确的对象 ID。

Markdown link tokenizer 支持嵌套括号 href。安全策略在 parser 阶段完成，后续 renderer 可直接读取 `safe` 标记。unsafe 链接保留原始 label 与 href，便于编辑器提示和使用者修复。
