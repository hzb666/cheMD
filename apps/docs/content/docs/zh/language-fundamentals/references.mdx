---
title: 引用、主对象别名与行内语法
description: Chemd 中 @ 引用、primary alias、元数据引用、模板参数引用和行内化学 token 的使用规则。
---

Chemd 的 Markdown 正文会保留原始文本，并额外提取引用、行内化学、行内代码和 Markdown 链接 token。引用解析由 resolver 在 AST 构建后执行。

## 对象引用

对象引用使用 `@id`。

```md
The selected entry is @rxn-var1.
```

resolver 在对象索引中查找 `rxn-var1`。对象索引来自所有带 ID 的 molecule、material、batch、reaction、result、analysis、procedure、trace、observation、sample、artifact 和 condition-varies 节点。

## 对象字段引用

字段引用使用 `@id.field`。

```md
The isolated yield is @res-var1.yield.
```

resolver 先定位对象，再读取字段。字段不存在时产生 `W_UNRESOLVED_REFERENCE`。

## 主对象别名

以下别名由 frontmatter 的 `primary_*` 字段绑定：

| 引用 | frontmatter 字段 |
| --- | --- |
| `@reaction.field` | `primary_reaction` |
| `@result.field` | `primary_result` |
| `@product.field` | `primary_product` |
| `@sample.field` | `primary_sample` |
| `@molecule.field` | `primary_molecule` |
| `@analysis.field` | `primary_analysis` |

```yaml
---
id: exp-condition-screen
title: Suzuki coupling condition screen
date: 2026-04-24
primary_reaction: rxn-var1
primary_result: res-var1
---
```

```md
The selected reaction uses @reaction.solvent and gives @result.yield.
```

主对象别名仅在带字段时归类为 `alias_field`。`@reaction` 本身会按普通对象 ID 查找。

## 元数据引用

元数据引用使用 `@meta.field`。

```md
Experiment @meta.id was recorded on @meta.date.
```

resolver 从 `document.meta` 读取字段。未声明字段会产生未解析引用诊断。

## condition-varies attempt 引用

`condition_varies` 节点允许通过字段名读取 attempt。

```md
:::condition-varies #cv-screen
standard: @rxn-standard
factor: solvent | baseline=THF
factor: temperature | baseline=25 C
outcome: yield | baseline=68%

attempt: var1
reaction: @rxn-var1
result: @res-var1
solvent: MeCN
temperature: 40 C
yield: 72%

attempt: var2
reaction: @rxn-var2
result: @res-var2
solvent: DMF
temperature: 60 C
yield: 45%
:::
```

```md
TLC analysis is attached to @cv-screen.var1.
```

resolver 在 `condition_varies.attempts` 中查找 ID 为 `var1` 的 attempt。

## 模板参数引用

模板展开期间支持 `@param.name`。

```md
:::template charge_one
params: reagent: ref<molecule> | amount: quantity<amount>
:::procedure #templated
step: charge | id=s-charge | inputs=@param.reagent | amount=@param.amount
:::
:::

:::use charge_one
reagent: mol-acid
amount: 1.0 mmol
:::
```

`@param.reagent` 和 `@param.amount` 只在模板上下文中解析。

## 行内化学

行内化学使用 `:chem[...]`。内容不能为空，且不能跨行。

```md
The substrate can be written inline as :chem[Brc1ccccc1].
```

解析器只提取 token 和位置信息。更深的化学规范化由后续服务或渲染流程处理。

## Markdown 链接安全标记

Markdown 链接会被提取为 `markdown_link` token，并包含 `safe` 标记。该标记供渲染和安全策略使用。

```md
[raw NMR file](data/nmr/var1.pdf)
```
