---
title: 派生表达式
description: Chemd typechecker 支持的等号派生数量表达式、函数、引用、单位和诊断。
---

派生表达式只在数量字段校验时生效。表达式必须以 `=` 开头，计算结果再交给数量解析器。

## 适用字段

当前实现通过 `readQuantity` 处理对象数量字段。可使用派生表达式的字段包括：

| 对象 | 字段 |
| --- | --- |
| reaction | `temperature`、`time`、`pressure` |
| reaction participant | `amount`、`mass`、`volume`、`equiv`、`equivalents` |
| result | `yield`、`conversion`、`selectivity`、`purity`、`isolated_mass` |
| material | `purity` |
| batch | `mass`、`purity` |
| sample | `purity` |

procedure step 参数的数量字段会执行数量解析，但当前不经过派生表达式求值。

## 字面量与运算符

表达式支持数字、数量字面量、字段引用、括号、一元负号和四则运算。

```md
:::result #res-derived
reaction: @rxn-main
status: success
isolated_mass: = 120 mg + 30 mg
yield: = percent(0.78, 1)
:::
```

数量加减要求单位相同。数量乘以数字、数量除以数字会保留原单位。除数为零会产生表达式错误。

## 字段引用

表达式中的字段引用写作 `@id.field`。目标字段必须存在，并且字段值必须是字符串。表达式解析器会把被引用值解析为数字、数量或字符串。

```md
:::result #res-calc
reaction: @rxn-main
status: success
isolated_mass: = @res-crude.isolated_mass * 0.72
:::
```

字段引用适合复用已记录的称量、转化率或产率。被引用字段缺失、非字符串或引用格式不合法时，表达式整体产生 `E_DERIVED_EXPRESSION_INVALID`。

## 函数

可用函数集合保持小而确定，便于校验和复现。

| 函数 | 语义 |
| --- | --- |
| `sum(a, b, ...)` | 累加参数 |
| `percent(value, denominator)` | 返回百分数量 |
| `ratio(value, denominator)` | 返回数值比 |
| `coalesce(a, b, ...)` | 返回第一个非空字符串值 |
| `to_unit(quantity, unit)` | 转换质量、物质的量、体积单位 |
| `theoretical_yield(a, b, ...)` | 依次相乘 |

`to_unit` 支持 `mg`、`g`、`kg`，`mmol`、`mol`，`mL`、`L` 的实现内转换。目标单位参数写作标识符，例如 `to_unit(1 g, mg)`。

## 诊断

表达式解析、引用解析、函数校验或运算规则失败时，typechecker 产生 `E_DERIVED_EXPRESSION_INVALID`。表达式求值成功后，结果仍需通过对应数量类别解析。数量类别不匹配时继续产生 `E403`。

## 最佳实践

```md
:::result #res-main
reaction: @rxn-main
product: @mol-product
status: success
isolated_mass: = to_unit(0.126 g, mg)
yield: = percent(0.84, 1)
purity: 98%
:::
```

派生表达式适合记录可追溯计算。实验原始值应保留在独立字段或相邻记录中，表达式字段用于生成标准化结果。
