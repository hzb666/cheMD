## `:::col` 布局块

`:::col` 生成 `ColNode`。header 参数为列数。列数必须是大于等于 1 的整数。

```md
:::col 2
col: {:::result #res-main
status: success
:::
:::}
col: {:::analysis #ana-main
type: tlc
data: TLC evidence
:::
:::}
:::
```

## `col:` 子项

`:::col` 的子项必须写作 `col:` 行。行内内容会生成 Markdown 子节点，`col: { ... }` 会解析括号内的 Markdown，`col: {:::` 会进入结构化块解析。

```md
:::col 2
col: left column summary with @reaction.solvent
col: right column summary with @result.yield
:::
```

结构化子项使用括号包裹，并以 `:::}` 结束。

```md
:::col 2
col: {:::result #res-left
status: success
:::
:::}
col: {:::analysis #ana-right
type: tlc
data: product spot observed
:::
:::}
:::
```

下面的直接嵌套块写法不会创建列子项。parser 会把非 `col:` 行报告为 `W_INVALID_COL_CHILD`，并可能因为子项数量不匹配产生 `W_COL_COUNT_MISMATCH`。

```md
:::col 2
:::result #res-left
status: success
:::
:::analysis #ana-right
type: tlc
data: product spot observed
:::
:::
```

## 结构化块嵌入列布局

`ColNode.children` 可以包含任意 `ChemdNode`。resolver 在构建对象索引、分配默认 ID 和解析节点时会递归处理 `col.children`。

```md
:::col 3
col: {:::chemd #mol-a
smiles: CCO
:::
:::}
col: {:::result #res-a
status: success
yield: 62 %
:::
:::}
col: {:::artifact #art-a
kind: nmr
path: data/nmr/a.jdx
:::
:::}
:::
```

三列内部的 molecule、result 和 artifact 都会按普通对象处理。`@mol-a`、`@res-a` 和 `@art-a` 在列布局之外也可引用。

## 列数校验

非法列数产生 `W_INVALID_COL_COLUMNS`，并回退为 1。子项数量与列数不一致产生 `W_COL_COUNT_MISMATCH`。

```md
:::col two
col: {:::result #res-invalid-columns
status: success
:::
:::}
:::
```

`two` 属于非整数列数，会产生 `W_INVALID_COL_COLUMNS` 并回退为 1。

```md
:::col 2
col: {:::result #res-only-child
status: success
:::
:::}
:::
```

列数为 2 但只有一个子块，会产生 `W_COL_COUNT_MISMATCH`。该诊断不阻止对象索引和引用解析。

## 语言层与渲染层边界

`col` 是 AST 中的布局节点。具体视觉表现由 HTML、DOCX bridge 或其他 renderer 决定。语言层只保存列数和子节点，不保存 CSS 或页面尺寸。

```md
:::col 2
col: {:::procedure #proc-left
step: charge substrate and solvent
:::
:::}
col: {:::observation #obs-right
event: color_change from colorless to yellow
:::
:::}
:::
```

源文件只表达两列和两个子节点。列宽、间距、断点和移动端堆叠方式由 renderer 决定。

## 推荐实践示例

`:::col` 用于表现层分组。语义对象仍应拥有稳定 ID，列内结构化子节点仍参与引用解析。

```md
:::chemd #mol-layout-substrate
smiles: CCO
:::

:::chemd #mol-layout-product
smiles: CC=O
:::

:::chemd #rxn-layout
reactant: @mol-layout-substrate | 1.0 mmol | 1.0 eq | limiting=true
product: @mol-layout-product
:::

:::col 2
col: Reaction @rxn-layout used @mol-layout-substrate.
col: {:::result #res-layout
reaction: @rxn-layout
product: @mol-layout-product
status: success
yield: 72 %
:::
:::}
:::
```
