领域模板用于创建完整 `.chemd` 文件。它不同于文件内 `:::template` 与 `:::use`；后者只在单个源文件内复用片段。

共享 catalog 位于 `@chemd/domain-templates`。CLI、web 和 desktop 都应读取这个 package，不复制模板正文。

```bash
pnpm chemd templates
pnpm chemd templates --json
pnpm chemd templates organic-synthesis/suzuki-screen
pnpm chemd new organic-synthesis/suzuki-screen --out exp.chemd
pnpm chemd new analytical/hplc-purity --out hplc.chemd --dry-run
```

- `photochemistry/photoredox`

每个 catalog entry 都在测试中按当前语言契约编译。模板只使用当前语法：没有 language/version 字段，没有旧 block 名，也没有兼容性 header。

## 模板内部复用

catalog 模板可以包含普通 Chemd `:::template` block，用于在生成文件里复用常见句子、method note 或 TLC lane note。method/profile reference 应表达为普通对象或引用，例如 HPLC method artifact 被 `analysis.method` 引用。
