---
title: 模板参数类型
description: Chemd 模板参数的声明、缺省类型、引用参数、数量参数、调用校验和展开限制。
---

模板参数只影响 `:::template` 与 `:::use`。它们让可复用模板声明必填参数，并在调用点校验引用或数量。

## 参数声明格式

`params` 支持同一行列表，也支持 YAML 风格列表。两种写法会被解析为相同的参数规格。

```md
params: label: string | sample: ref<sample> | amount: quantity<amount>
```

```md
params:
  - label: string
  - sample: ref<sample>
  - amount: quantity<amount>
```

参数名必须以字母或 `_` 开头，后续允许字母、数字和 `_`。非法参数名会被忽略。未知类型按 `string` 处理。

## `string`

`string` 是缺省类型。省略类型时，resolver 采用字符串参数。

```md
:::template note-line
params: label | method: string
@param.label was checked by @param.method.
:::
```

`string` 不检查对象存在性或数量单位。需要稳定关系时使用 `ref<kind>`。

## `ref<kind>`

`ref<kind>` 要求调用值指向已存在对象，并要求对象类型匹配。调用值可写裸 ID，也可写 `@id`。resolver 会去掉开头 `@`，并忽略 `.field` 后缀。

支持的 `kind`：

| kind | 目标节点 |
| --- | --- |
| `molecule` | molecule |
| `reaction` | reaction |
| `result` | result |
| `analysis` | analysis |
| `procedure` | procedure |
| `observation` | observation |
| `sample` | sample |
| `artifact` | artifact |
| `condition_varies` | condition screen |

```md
:::template sample-analysis
params: sample: ref<sample> | analysis: ref<analysis>
Sample @param.sample is supported by analysis @param.analysis.
:::

:::use sample-analysis
sample: @sample-main
analysis: an-hplc
:::
```

目标缺失或类型不匹配会产生 `E_TEMPLATE_PARAM_TYPE_MISMATCH`。

`ref<kind>` 校验当前只使用源文档的本地对象索引。跨文档 ID 和 external target 可用于路线或 workspace 场景，但目前不能通过模板参数类型校验。若模板有意接收外部引用，应使用 `string` 参数。

## `quantity<class>`

`quantity<class>` 要求调用值符合数量文本。支持的类别与单位来自 resolver 单位集合。

| class | 支持单位 |
| --- | --- |
| `amount` | `mmol`、`mol` |
| `mass` | `mg`、`g`、`kg` |
| `volume` | `ml`、`mL`、`l`、`L` |
| `temperature` | `C`、`°C`、`℃`、`K`、`F` |
| `time` | `h`、`hr`、`hrs`、`min`、`mins`、`分钟`、`小时` |
| `pressure` | `bar`、`atm`、`psi` |
| `concentration` | `M`、`mM` |
| `equivalent` | `equiv`、`eq` |
| `percent` | `%`、`percent` |

```md
:::template charge
params: reagent: ref<molecule> | amount: quantity<amount>
:::procedure #charge-template
step: charge | id=s-charge | inputs=@param.reagent | amount=@param.amount
:::
:::

:::use charge
reagent: mol-substrate
amount: 1.00 mmol
:::
```

省略类别的 `quantity` 接受任意实现支持的数量单位。

## 必填与展开限制

模板声明中的每个参数均为必填参数。`:::use` 中缺少参数或参数为空字符串时产生 `E_TEMPLATE_PARAM_MISSING`。

resolver 限制模板展开深度为 32，展开节点总数为 2000。递归模板产生 `E_TEMPLATE_CYCLE`。超过展开限制产生 `E_TEMPLATE_EXPANSION_LIMIT`。

## 最佳实践

模板适合重复的实验叙述与过程结构。对象关系使用 `ref<kind>`，可计算或可归一化的数值使用 `quantity<class>`，自由标签使用 `string`。

```md
:::template screen-result-row
params:
  - attempt: string
  - reaction: ref<reaction>
  - product: ref<molecule>
  - yield: quantity<percent>

Attempt @param.attempt used @param.reaction and assigned @param.yield to @param.product.
:::
```
