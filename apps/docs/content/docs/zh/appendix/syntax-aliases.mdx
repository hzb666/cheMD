---
title: 语法别名对照
description: Chemd 字段别名、行内别名和可接受的简写字段。
---

本页列出当前 Chemd parser 与 resolver 接受的字段别名和简写。新文档建议优先使用规范字段；紧凑写作场景可使用已实现的简写。

## `kind` 值别名

| 别名 | 规范值 | 适用位置 | 说明 |
| --- | --- | --- | --- |
| `mol` | `molecule` | `:::chemd` 的 `kind` | 官方紧凑值。 |
| `reac` | `reaction` | `:::chemd` 的 `kind` | 官方紧凑值。 |

```md
:::chemd #mol-solvent
kind: mol
smiles: CCO
:::

:::chemd #rxn-main
kind: reac
reactant: @mol-a | 1.0 mmol | 1.0 eq | limiting=true
product: @mol-b
:::
```

## Reaction 字段别名

| 别名或简写 | 规范字段 | 适用位置 | 说明 |
| --- | --- | --- | --- |
| `reactant` | `reactant` | `:::chemd` reaction | 可重复的结构化 participant 字段。 |
| `reac` | `reactant` | `:::chemd` reaction | 紧凑的可重复 participant 字段。 |
| `reactants` | `reactant` | `:::chemd` reaction | 简单 `|` 列表别名；不要写 amount、equiv 或 `limiting=true`。 |
| `product` | `product` | `:::chemd` reaction | 可重复的结构化 participant 字段。 |
| `prod` | `product` | `:::chemd` reaction | 紧凑的可重复 participant 字段。 |
| `products` | `product` | `:::chemd` reaction | 简单 `|` 列表别名；不要写结果数量。 |
| `reaction_smiles` | `rxn_smiles` | `:::chemd` reaction | reaction structure 别名。显式值必须与 participant 一致。 |

```md
:::chemd #rxn-main
kind: reaction
reac: @mol-a | 1.0 mmol | 1.0 eq | limiting=true
reac: @mol-b | 1.2 eq
prod: @mol-c
:::
```

## Primary 行内别名

Primary 行内别名通过 frontmatter 的 `primary_*` 字段解析。它们只在带字段名时有效。

| 行内别名 | Frontmatter 来源 | 示例 |
| --- | --- | --- |
| `@reaction.field` | `primary_reaction` | `@reaction.solvent` |
| `@result.field` | `primary_result` | `@result.yield` |
| `@product.field` | `primary_product` | `@product.name` |
| `@sample.field` | `primary_sample` | `@sample.purity` |
| `@molecule.field` | `primary_molecule` | `@molecule.smiles` |
| `@analysis.field` | `primary_analysis` | `@analysis.data` |

```md
---
primary_reaction: rxn-main
primary_result: res-main
---

The primary reaction used @reaction.solvent and gave @result.yield.
```

## Result 与条件筛选别名

| 别名或简写 | 规范含义 | 适用位置 | 说明 |
| --- | --- | --- | --- |
| `ref` | reaction association | `:::result` | 当 `reaction` 缺省时，作为 reaction link 处理。 |
| `reaction` | reaction association | `:::result` | 显式 reaction link；需要关系清晰时推荐使用。 |
| `note` / `notes` | attempt note | `:::condition-varies` attempt section | 两种写法都会写入当前 attempt note。 |
| `attempt:` 后第一个 segment | attempt ID | `:::condition-varies` | `attempt: mecn-40` 开启 attempt `mecn-40`。 |

```md
:::condition-varies #screen-main
standard: @rxn-standard
factor: solvent | baseline=MeCN
factor: temperature | baseline=40 C
outcome: yield | baseline=68%

attempt: dmf-60
reaction: @rxn-var1
result: @res-var1
solvent: DMF
temperature: 60 C
yield: 72%
note: cleaner profile
:::
```

## Procedure 与 Observation 别名

| 别名 | 规范字段 | 适用位置 | 说明 |
| --- | --- | --- | --- |
| `step_id` | `id` | `step:` 与嵌套 `:::step` | 设置显式 step ID。 |
| `depends_on` | `dependsOn` | `step:` 与嵌套 `:::step` | 接受逗号分隔的依赖 step ID。 |
| `event_id` | `id` | `event:` 与嵌套 `:::event` | 设置显式 event ID。 |
| `event_type` / `type` | `eventType` | `event:` 与嵌套 `:::event` | 设置 event type。 |
| `linked_step` | `linkedStep` | `event:` 与嵌套 `:::event` | 把 event 关联到 step ID。 |

```md
:::procedure #proc-main
step: add | step_id=s-add | inputs=@mol-a | outputs=@mol-b
step: analyze | id=s-tlc | depends_on=s-add
:::

:::observation #obs-main
event: color-change | event_id=e-color | linked_step=s-add
event: event_type=tlc-check | id=e-tlc | linkedStep=s-tlc
:::
```

## Template Bind 别名

模板 `bind` 是使用者自定义别名。它可以指向对象 ID 或 primary frontmatter 字段，`:::use` 可通过同名字段覆盖绑定值。

```md
:::template reaction-summary
bind: rxn=primary_reaction | res=primary_result
Reaction @rxn.name gave @res.yield.
:::

:::use reaction-summary
rxn: rxn-variant
res: res-variant
:::
```
