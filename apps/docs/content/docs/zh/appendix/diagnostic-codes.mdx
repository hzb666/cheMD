title: 诊断码速查
description: Chemd parser、resolver、typechecker、compiler 和 runtime 常见诊断码速查。
---

下列内容按来源和用途列出常见诊断码。你可以据此判断问题来自解析、引用解析、语义校验、编译还是运行准备。

## 语法与 Frontmatter

| 诊断码 | 含义 |
| --- | --- |
| `E_MISSING_REQUIRED_FRONTMATTER_KEY` | 缺少 `id`、`title` 或 `date` |
| `E_INVALID_FRONTMATTER_VALUE` | frontmatter 值类型或结构非法 |
| `W_DUPLICATE_FRONTMATTER_KEY` | frontmatter key 重复 |
| `W_NON_ISO_FRONTMATTER_DATE` | 日期格式不匹配 `YYYY-MM-DD` |
| `W_INVALID_FRONTMATTER_DATE_VALUE` | 日期格式匹配但日历值非法 |
| `W_INVALID_FRONTMATTER_LINE` | frontmatter 行无法解析 |
| `E_INVALID_ID` | 块 ID 不符合规则 |
| `W_UNKNOWN_BLOCK` | 块类型未实现；以 error severity 报告 |
| `W_UNTERMINATED_BLOCK` | 结构化块未闭合 |
| `W_UNKNOWN_FIELD` | 字段不在块允许集合内；以 error severity 报告 |
| `E_INVALID_LIST_ITEM` | 列表字段包含空项 |
| `W_UNSAFE_LINK_HREF` | Markdown 链接 href 未通过安全策略 |
| `E_TLC_LANE_REQUIRED` | TLC lane item 出现在 `lane:` 之前 |
| `E_CONDITION_DSL_FIELD` | 条件筛选包含非法 section 字段 |
| `E_CONDITION_DSL_ORDER` | 条件筛选声明写在 attempt 之后 |
| `E_CONDITION_ATTEMPT_ID` | 条件筛选 attempt ID 缺失或重复 |
| `E_CONDITION_DSL_DECLARATION` | 条件筛选 factor/outcome 声明非法 |
| `E_CONDITION_ATTEMPT_DUPLICATE_FIELD` | attempt 重复填写已声明的 factor 或 outcome |
| `E_CONDITION_ATTEMPT_UNKNOWN_FIELD` | attempt 字段未声明为 factor 或 outcome |

## 已移除的 Legacy Blocks

| 诊断码 | 含义 |
| --- | --- |
| `W_CHEMD_KIND_AMBIGUOUS` | 省略 `kind` 且 parser 无法稳定推断类型 |
| `E_CHEMD_KIND_CONFLICT` | `kind` 非法，或显式类型与字段形状冲突 |
| `W_INVALID_CHEMD_IMPLICIT_VALUE` | molecule 隐式 SMILES 行数非法 |

## Resolver

| 诊断码 | 含义 |
| --- | --- |
| `E_DUPLICATE_ID` | 对象 ID 重复 |
| `E_DUPLICATE_TEMPLATE` | 模板名重复 |
| `E_MISSING_REQUIRED_FIELD` | 对象缺失 resolver 必填字段 |
| `W_UNRESOLVED_REFERENCE` | 引用目标或字段无法解析 |
| `E_INVALID_PRIMARY_REFERENCE` | `primary_*` 指向不存在对象 |
| `E_UNKNOWN_TEMPLATE` | legacy `:::use` 找不到对应 `:::template` |
| `E_TEMPLATE_CYCLE` | 模板递归 |
| `E_TEMPLATE_EXPANSION_LIMIT` | 模板展开超过深度或节点限制 |
| `E_TEMPLATE_PARAM_MISSING` | 模板调用缺少参数 |
| `E_TEMPLATE_PARAM_TYPE_MISMATCH` | 模板参数类型不匹配 |

## Typechecker

| 诊断码 | 含义 |
| --- | --- |
| `E306` | result `status` 值非法 |
| `E401` | unit 不适用于目标数量类别 |
| `E402` | percent 数量超出 0 到 100 |
| `E403` | 数量无法按目标类别解析 |
| `W_QUANTITY_UNIT_SPACING` | 普通数量单位可识别但应与数字分隔 |
| `W_QUANTITY_UNIT_CASING` | 单位大小写可归一但不符合规范写法 |
| `E301` | v0.3 缺失必填字段诊断 |
| `E_TYPED_REFERENCE_MISMATCH` | 引用目标类型不匹配 |
| `E_MOLECULE_IDENTITY_MISSING` | molecule 缺少身份字段 |
| `E_MOLECULE_REACTION_QUANTITY` | 反应用量写在 molecule 上 |
| `E_INTEROP_SMILES_PARSE` | SMILES 身份字段表面解析失败 |
| `E_INTEROP_INCHI_FORMAT` | InChI 身份字段没有以 `InChI=` 开头 |
| `E_INTEROP_INCHIKEY_FORMAT` | InChIKey 不符合标准 14-10-1 分段格式 |
| `E_INTEROP_RXN_SMILES_PARSE` | RXN SMILES 字段不是有效 `reactants>>products` 表面 |
| `E_INTEROP_RXN_SMILES_UNVERIFIED` | RXN SMILES 无法根据全部 participant 身份验证 |
| `E_INTEROP_RXN_SMILES_PARTICIPANT_CONFLICT` | RXN SMILES 与 reaction participant 身份冲突 |
| `E_REACTION_PARTICIPANT_MISSING` | reaction 缺少 reactant 或 product participant |
| `E_REACTION_PARTICIPANT_SYNTAX` | 结构化 participant 事实使用了非法表面语法 |
| `E_REACTION_PARTICIPANT_PRODUCT_QUANTITY` | product participant 含有非法数量 |
| `E_STOICHIOMETRY_LIMITING` | limiting reactant 规则被破坏 |
| `E_STOICHIOMETRY_QUANTITY_MISSING` | 化学计量 participant 缺少 amount 或 equivalent |
| `E_RESULT_REACTION_CONFLICT` | result 与 linked reaction 字段冲突 |
| `E_TLC_LABEL_UNKNOWN` | TLC spot 或 lane label 不是支持的内置 label |
| `E_TLC_SPOT_REFERENCE` | TLC spot 引用无法唯一解析 |
| `E_TLC_UNKNOWN_REFERENCE` | TLC `unknown` 引用无法解析为已知 spot |
| `E_TLC_SPOT_LABEL_REQUIRED` | 混合 TLC lane 中存在未标注 spot |
| `E_ANALYSIS_FIELD_FOR_TYPE` | analysis 字段与声明的 analysis 类型不匹配 |
| `E_ANALYSIS_PEAK_SYNTAX` | analysis peak 无法按声明类型解析 |
| `E_ANALYSIS_SPECTRUM_CONFLICT` | NMR spectrum 元数据与显式字段冲突 |
| `E_ANALYSIS_ION_REQUIRED` | LCMS/GCMS 有 peak 但缺少 ion 数据 |
| `E_ANALYSIS_ION_SYNTAX` | MS ion 行缺少 m/z 值 |
| `E_CONDITION_OUTCOME_MISSING` | attempt 缺少已声明 outcome |
| `E_CONDITION_BASELINE_CONFLICT` | outcome baseline 与 standard result 冲突 |
| `E_CONDITION_OUTCOME_CONFLICT` | attempt outcome 与 linked result 冲突 |
| `E_DERIVED_EXPRESSION_INVALID` | 派生表达式非法 |
| `W_REACTION_ROUTE_MISMATCH` | reaction route 前驱路线不一致 |
| `E_REACTION_ROUTE_CYCLE` | reaction route 成环 |
| `W_REACTION_ROUTE_ORPHAN` | route 中存在孤立 reaction |

## Procedure 与 Observation

| 诊断码 | 含义 |
| --- | --- |
| `E_STEP_INVALID_FAMILY` | step family 未实现 |
| `E_STEP_MISSING_FIELD` | step 结构缺少必要字段 |
| `E_STEP_PARAM_MISSING` | step family 必需参数缺失 |
| `E_STEP_PARAM_INVALID` | step family 不允许该参数 |
| `E_STEP_PARAM_TYPE_MISMATCH` | step family 参数值不符合 schema 类型 |
| `E_STEP_ID_DUPLICATE` | step ID 重复 |
| `E_STEP_INVALID_REFERENCE` | `dependsOn` 指向不存在 step |
| `E_STEP_DEPENDENCY_CYCLE` | step 依赖图成环 |
| `E_PROCEDURE_CONTROL_SYNTAX` | procedure control 大括号或行语法非法 |
| `E_PROCEDURE_CONTROL_UNCLOSED` | procedure control block 缺少闭合大括号 |
| `E_PROCEDURE_CONTROL_ID` | procedure control 缺少 ID |
| `E_PROCEDURE_CONTROL_ID_DUPLICATE` | procedure control ID 重复或与 step 冲突 |
| `E_PROCEDURE_CONTROL_COUNT` | `repeat` count 缺失或非法 |
| `E_PROCEDURE_CONTROL_BODY` | 需要子内容的 control body 为空 |
| `E_PROCEDURE_CONTROL_CONDITION` | control condition 缺失、含义不清或无法解析 |
| `E_PROCEDURE_CONTROL_BRANCH` | branch control 缺少有效 `case` 或 `default` 结构 |
| `E_PROCEDURE_CONTROL_PARALLEL` | parallel control 缺少至少两个有效 path |
| `W_PROCEDURE_CONTROL_DYNAMIC` | 动态 control 需要 runtime review |
| `E_OBSERVATION_EVENT_INVALID_TYPE` | event type 未实现 |
| `E_OBSERVATION_LINKED_STEP_MISSING` | event 指向不存在 step |
| `E_TRACE_PLAN_REFERENCE` | trace block 未引用 procedure plan |
| `E_TRACE_EVENT_TIME` | trace event 时间不是 ISO datetime 或不单调 |
| `E_TRACE_EVENT_REFERENCE` | trace event 引用未知 step、control、artifact、analysis 或 result |
| `E_TRACE_EVENT_PAYLOAD` | trace event payload 缺少必填字段 |
| `W_TRACE_STEP_STATE` | trace step 状态顺序可疑，或对 replay 非法 |

## Program Language

| --- | --- |
| `E_PROGRAM_META_EXPECTED` | 缺少 `meta` 声明 |
| `E_PROGRAM_DECLARATION_EXPECTED` | 解析器需要一个 program 声明 |
| `E_PROGRAM_DECLARATION_KIND_UNKNOWN` | program-v1 不支持该声明类型 |
| `E_PROGRAM_BLOCK_OPEN_EXPECTED` | 声明或字段块缺少 `{` |
| `E_PROGRAM_BLOCK_CLOSE_EXPECTED` | 声明或字段块缺少 `}` |
| `E_PROGRAM_FIELD_NAME_EXPECTED` | 缺少字段名 |
| `E_PROGRAM_FIELD_COLON_EXPECTED` | 字段名后缺少 `:` |
| `E_PROGRAM_FIELD_UNKNOWN` | 当前声明不接受该字段 |
| `E_PROGRAM_EXPECTED_VALUE` | 字段值无法解析 |
| `E_PROGRAM_EXPECTED_CALL_ARG_ASSIGNMENT` | 调用参数缺少 `:` 赋值 |
| `E_PROGRAM_UNEXPECTED_TOKEN` | 解析器遇到意外 token |
| `E_DUPLICATE_DECLARATION` | 声明 ID 重复 |
| `E_DUPLICATE_QUALIFIED_DECLARATION` | 完整声明 ID 重复 |
| `E_UNRESOLVED_PROGRAM_REFERENCE` | program 引用无法解析 |
| `W_UNRESOLVED_DOC_REFERENCE` | 文档注释引用无法解析 |
| `E_LEGACY_` | 检测到已移除的 legacy 语法 |
| `E_LEGACY_FRONTMATTER_REMOVED` | program-v1 已移除 legacy metadata |
| `E_LEGACY_FENCED_BLOCK_REMOVED` | program-v1 已移除 legacy `:::` 结构块 |
| `E_LEGACY_TEMPLATE_REMOVED` | program-v1 已移除 legacy `:::template` 和 `:::use` 语法 |
| `E_LEGACY_COLUMN_LAYOUT_REMOVED` | program-v1 已移除 legacy `:::col-N` rendered layout 语法 |

## Program Procedure 与 Agent

| 诊断码 | 含义 |
| --- | --- |
| `E_PROGRAM_PROCEDURE_EXPECTED` | 解析器需要 procedure 声明 |
| `E_PROGRAM_PROCEDURE_ID_EXPECTED` | procedure 声明缺少 ID |
| `E_PROGRAM_PROCEDURE_BLOCK_EXPECTED` | procedure 缺少块体 |
| `E_PROGRAM_PROCEDURE_STATEMENT_EXPECTED` | procedure 语句无法解析 |
| `E_PROGRAM_PROCEDURE_STEP_EXPECTED` | 解析器需要 `step` 语句 |
| `E_PROGRAM_PROCEDURE_STEP_ID_EXPECTED` | procedure step 缺少 ID |
| `E_PROGRAM_PROCEDURE_STEP_ASSIGN_EXPECTED` | procedure step 缺少 `=` |
| `E_PROGRAM_PROCEDURE_STEP_CALL_EXPECTED` | procedure step 缺少调用表达式 |
| `E_PROGRAM_AGENT_EXPECTED` | 解析器需要 agent 声明 |
| `E_PROGRAM_AGENT_RUN_EXPECTED` | 解析器需要 `agent run` |
| `E_PROGRAM_AGENT_RUN_ID_EXPECTED` | agent run 缺少 ID |
| `E_PROGRAM_AGENT_BLOCK_EXPECTED` | agent run 缺少块体 |
| `E_AGENT_TOOL_UNKNOWN` | agent tool 名称未知 |
| `E_AGENT_PATCH_TARGET_UNRESOLVED` | agent patch 目标无法解析 |
| `E_AGENT_PATCH_DECISION_ORPHAN` | agent decision 未关联已有 patch |
| `E_AGENT_RUN_STATUS_INCOMPLETE` | completed agent run 缺少终态审计事件 |

## Interoperability 与 Training Governance

| 诊断码 | 含义 |
| --- | --- |
| `E_INTEROP_RXN_SMILES_MISSING` | 下游 interop adapter 需要显式 reaction structure，但无法推断 |
| `W_INTEROP_UNVERIFIED_IDENTITY` | 同一 molecule 有多个身份字段，但没有外部 verifier 证明一致 |
| `W_INTEROP_PLACEHOLDER_NOT_COMPLIANT` | 外部标准导出只是 placeholder mapping，不是 validator-backed compliant export |
| `E_TRAINING_PII_PRESENT` | governance 标记 PII present，因此只允许 audit/full export |
| `W_TRAINING_RAG_NOT_ALLOWED` | `allowed_uses` 不包含 `rag`；阻断 non-audit projection |
| `W_TRAINING_AUDIT_ONLY` | governance 仅允许 audit 用途；阻断 non-audit projection |
| `W_TRAINING_SANITIZATION_DISABLED` | 允许 non-audit training use，但 sanitization 被禁用；阻断 sanitized projection |
| `W_TRAINING_REVIEW_REQUIRED` | training export 存在需要 review 的质量或 governance 条件 |
| `E501` | procedure lowering 失败 |
| `E504` | analysis step 未绑定 |
| `E505` | observation stage 存在歧义 |
| `W_PROCEDURE_PROSE_LOWERED` | procedure prose 被启发式降低为步骤 |
| `W_OBSERVATION_PROSE_LOWERED` | observation prose 被启发式降低为事件 |
| `W805` | step extraction 置信度偏低 |
| `W806` | observation prose 可以表达为结构化 event |
| `I903` | procedure lowering 已成功完成 |

## 修复顺序

优先修复 error，再处理 warning。推荐顺序为 frontmatter、块 ID、未知字段、必填字段、引用、模板参数、数量、步骤依赖、路线图。
