---
title: 数量单位
description: Chemd typechecker 与模板参数校验支持的数量类别、单位、规范单位和派生表达式单位转换。
---

Chemd 会保留原始数量文本，并在校验时为支持的数量类别计算规范值。

## 数量类别

| 类别 | 支持单位 | 规范单位 |
| --- | --- | --- |
| `amount` | `mmol`、`mol` | `mmol` |
| `mass` | `mg`、`g`、`kg` | `mg` |
| `volume` | `mL`、`L`，小写形式会产生 warning | `mL` |
| `temperature` | `C`、`°C`、`℃`、`K`、`F` | 按输入类别保留 |
| `time` | `h`、`hr`、`hrs`、`min`、`mins`、`分钟`、`小时` | `h` |
| `pressure` | `bar`、`atm`、`psi` | `bar` |
| `concentration` | `M`、`mM` | `M` |
| `equivalent` | `equiv`、`eq` | `equiv` |
| `percent` | `%`、`percent` | `percent` |
| `rate` | `mL/min`、`L/min` | `mL/min` |
| `rpm` | `rpm` | `rpm` |
| `ph` | `pH` | `pH` |

`rt` 与 `r.t.` 是室温 shorthand。`overnight` 是时间 shorthand。temperature program 也使用同一套数量解析，例如 `r.t. -> 80 C over 30 min`。

带单位数量必须在数值和单位之间保留空格。`78 %` 与 `1.0 mmol` 合法；`78%` 与 `1.0mmol` 是 error。reaction participant 的 equivalent 也接受不带单位的 `equiv=1.2`。单位大小写可归一时会产生 warning。

## 字段映射

| 对象或语法 | 字段 | 数量类别 |
| --- | --- | --- |
| reaction | `temperature` | `temperature` |
| reaction | `time` | `time` |
| reaction | `pressure` | `pressure` |
| reaction participant | `amount` | `amount` |
| reaction participant | `mass` | `mass` |
| reaction participant | `volume` | `volume` |
| reaction participant | `equiv`、`equivalents` | `equivalent` |
| result | `yield`、`conversion`、`selectivity`、`purity` | `percent` |
| result | `isolated_mass` | `mass` |
| material | `purity` | `percent` |
| batch | `mass` | `mass` |
| batch | `purity` | `percent` |
| sample | `purity` | `percent` |
| step params | `amount`、`mass`、`volume`、`temperature`、`target_temperature`、`duration`、`time`、`pressure`、`concentration`、`equivalent`、`equivalents`、`percent`、`rate`、`rpm`、`ph` | 对应类别 |

## 示例

reaction participant 中，带 amount 单位的段可以省略 `amount=`。equivalent 可以写 `eq`、`equiv` 或 `equiv=...`。limiting reactant 必须同时有 amount 和 equivalent。

```md
:::chemd #rxn-main
reactant: @mat-substrate | 1.00 mmol | 1.0 eq | limiting=true
reactant: @mol-base | equiv=1.2
reac: @mol-catalyst | 0.05 eq
product: @mol-product
temperature: r.t. -> 80 C over 30 min
pressure: 1 bar
:::
```

step 参数复用同一套解析器。rate 与 pH 是结构化数量，因此可进入 runtime preflight 和 typed graph 输出。

```md
:::procedure #proc-quantity
step: add | id=s-add | reagent=@mat-base | volume=2.0 mL | rate=0.5 mL/min
step: mix | id=s-stir | rpm=600 rpm | duration=30 min
step: observe | id=s-ph | ph=pH 7.2
step: heat | id=s-heat | temperature=r.t. -> 80 C over 30 min
:::
```

## 模板参数

`quantity<class>` 使用 resolver 单位集合执行形态检查。`quantity` 不带类别时，接受任意实现支持的数量单位。

```md
params: amount: quantity<amount> | yield: quantity<percent>
```

## 派生表达式单位转换

派生表达式的 `to_unit(quantity, unit)` 支持质量、物质的量和体积转换：

- `mg`、`g`、`kg`
- `mmol`、`mol`
- `mL`、`L`

```md
isolated_mass: = to_unit(0.126 g, mg)
```

## 诊断

数量文本无法匹配目标类别时产生 `E403`。紧凑的数字-单位写法也产生 `E403`。percent 数量小于 0 或大于 100 时产生 `E402`。单位大小写不规范产生 `W_QUANTITY_UNIT_CASING`。表达式求值失败时产生 `E_DERIVED_EXPRESSION_INVALID`。
