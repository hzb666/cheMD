附录提供速查内容。使用者可在写作时快速确认支持范围，工具开发者可用这些页面核对实现边界。

## 章节

- [实现特性索引](/zh/docs/appendix/feature-inventory)：当前代码库已实现的语言面。
- [语法摘要](/zh/docs/appendix/syntax-summary)：frontmatter、行内语法、结构化块和模板语法摘要。
- [数量单位](/zh/docs/appendix/quantity-units)：typechecker 和模板参数校验支持的数量类别与单位。
- [语法别名对照](/zh/docs/appendix/syntax-aliases)：Chemd 字段别名、行内别名和可接受的简写字段。
- [诊断码速查](/zh/docs/appendix/diagnostic-codes)：常见 parser、resolver、typechecker 和 compiler 诊断码。
