---
title: 导出输出
description: Chemd 的导出菜单、输出格式，以及每种投影的使用场景。
---

Chemd 导出是对一个已编译文档或一组已编译文档的投影。它们都来自同一条 parser、resolver、typechecker、step graph、runtime plan 和 render profile 管线，但每种格式保留的结构不同。

## 格式总览

| 输出 | 主要命令或字段 | 适用场景 |
| --- | --- | --- |
| HTML | `compileChemd(source).html` | 浏览器预览、网页发布、人工审阅 |
| JSON + semantic graph | `pnpm chemd export file.chemd --format json` | 类 AST 结构输出和 typed semantic graph |
| DOCX bridge | `compileChemd(source).docxBridge` | 通过 Node bridge 进行 Markdown-to-DOCX 转换 |
| LNF | `pnpm chemd export file.chemd --format lnf` | canonical lab/runtime facts、step graph、controls 和 preflight summaries |
| Training full | `pnpm chemd export file.chemd --format training-full` | 可审计 source、semantic、learning 和 quality layers |
| Training understanding | `pnpm chemd export file.chemd --format training` | sanitized training 与 reasoning projection |
| RAG | `pnpm chemd export file.chemd --format rag` | retrieval chunks 和搜索 metadata |
| Graph index | `pnpm chemd graph *.chemd --format json` | 跨文档 graph、reaction clusters 和 reaction map 输入 |

## 共享编译输出

`compileChemd` 返回这些导出相关字段：

```ts
const result = compileChemd(source);

result.html;
result.json;
result.docxBridge;
result.lnf;
result.ragExport;
result.trainingUnderstanding;
result.trainingExport;
result.typedSemanticGraph;
result.stepGraph;
```

CLI `export` 命令暴露 `json`、`lnf`、`rag`、`training` 和 `training-full`。HTML 与 DOCX 是 compile/app 输出，不是当前 CLI `export --format` 值。`graph` 命令会编译多个文件，并从它们的 training understanding 构建 graph index。

Field value schema metadata 是 compiler/tooling contract，不是单独的导出格式。它用于对齐编辑器补全和 typed quantity 字段，同时保持现有 JSON、semantic graph、training、RAG、HTML、DOCX 和 LNF 输出形状不变。

## 最小源文件示例

本节示例使用下面的 program-first 紧凑记录：

```text
module exp_export_example

meta {
  id: "exp-export-example"
  title: "Export example"
  date: "2026-05-21"
  primary_reaction: @rxn_main
  primary_result: @res_main
}

molecule mol_a {
  name: "substrate A"
  smiles: "CCO"
}

molecule mol_b {
  name: "product B"
  smiles: "CC=O"
}

reaction rxn_main {
  reactants: [@mol_a]
  products: [@mol_b]
  solvent: "MeCN"
  temperature: 60 C
}

result res_main for @rxn_main {
  status: success
  yield: 78%
}

analysis ana_main for @res_main {
  type: nmr
  ref: @res_main
}

procedure proc_main for @rxn_main {
  evidence: [@res_main]
  step add = add(inputs: [@mol_a], outputs: [@mol_b])
}

observation obs_main for @rxn_main {
  notes: "yellow solution"
}
```
