Training 与 RAG 导出来自 `@chemd/exporter-training`。

```bash
pnpm chemd export ./examples/example.chemd --format training-full
pnpm chemd export ./examples/example.chemd --format training
pnpm chemd export ./examples/example.chemd --format rag
```

## `training-full`

`training-full` 返回 `ChemdTrainingExportV2`，schema version 为 `chemd-training-export/v0.2`。它是可审计导出，会保留 source context。

顶层字段：

- `schema_version`、`export_id`、`exported_at`
- `generator`
- `document`
- `governance`
- `source_layer`
- `semantic_layer`
- `learning_layer`
- `quality_layer`

`semantic_layer` 包含 `molecules`、`materials`、`batches`、`reactions`、`results`、`analyses`、`samples`、`artifacts`、`condition_variations`、`condition_variation_attempts`、`markdown_blocks`、`links` 和可选 `lnf`。

`learning_layer` 包含 `retrieval_chunks`、`prediction_instances`、`chemistry_feature_refs`、`procedure_to_steps` 和 `observation_to_events`。

示例：

            "raw": "@mol-a | 1.0 mmol | 1.0 eq",

          }
        ],

## `training`

`training` 返回 `ChemdTrainingUnderstandingV1`，schema version 为 `chemd-training-understanding/v0.1`。它是 sanitized training projection。Governance 可以阻止该投影；被阻止时保留 quality metadata，但移除 training entities 和 graph content。

它包含：

- `entities`：sanitized molecules、materials、reactions、results、analyses、samples、artifacts、condition variations、condition attempts 和 narrative blocks
- `relations`
- `resolved_references`
- `procedure_logic`
- `experiment_logic`：outcomes、design contexts、outcome quality、taxonomy、expert routing、intent hypotheses、variable logic、causal links、material flow graph、step dependencies、reaction routes、evidence links、sample profiles 和 artifact profiles
- `knowledge_graph`
- `lora_generation_hints`
- `quality`

示例：

```json
{
  "schema_version": "chemd-training-understanding/v0.1",
  "entities": {
    "reactions": [{ "entity_id": "reaction::rxn-main", "original_id": "rxn-main" }],
    "results": [{ "entity_id": "result::res-main", "yield_percent": 78 }],
    "analyses": [{ "entity_id": "analysis::nmr-main", "analysis_type": "nmr" }],
    "condition_variation_attempts": [
      { "entity_id": "condition-variation-attempt::screen-a.a1", "attempt_id": "a1" }
    ],
    "narrative_blocks": []
  },
  "procedure_logic": {
    "procedure_to_steps": [
      { "procedure_id": "proc-main", "steps": [{ "step_id": "s-add", "family": "add" }] }
    ],
    "observation_to_events": [
      { "observation_id": "obs-main", "events": [{ "event_id": "e-color" }] }
    ]
  },
  "experiment_logic": {
    "outcomes": [
      {
        "result_entity_id": "result::res-main",
        "reaction_entity_id": "reaction::rxn-main",
        "yield_percent": 78
      }
    ],
    "material_flow_graph": { "nodes": [], "edges": [] },
    "step_dependencies": []
  },
  "quality": {
    "usable_for_training": true,
    "confidence_score": 0.9,
    "warnings": []
  }
}
```

## `rag`

`rag` 返回 `ChemdRagExportV1`，schema version 为 `chemd-rag-export/v0.1`。它包含 `document`、`governance`、`chunks` 和 `quality`。

RAG chunk 是 sanitized retrieval chunk。它保留 chunk type、source entity IDs、text 和 metadata，但省略 audit-only raw text。

示例：

```json
{
  "schema_version": "chemd-rag-export/v0.1",
  "chunks": [
    {
      "chunk_id": "chunk::exp-export-example::reaction-summary::rxn-main",
      "chunk_type": "reaction_summary",
      "source_entity_ids": ["reaction::rxn-main", "result::res-main"],
      "text": "rxn-main used mol-a and gave res-main in 78% yield.",
      "metadata": {
        "date": "2026-05-21",
        "reaction_ids": ["reaction::rxn-main"],
        "result_ids": ["result::res-main"],
        "analysis_ids": ["analysis::nmr-main"],
        "yield_percent": 78,
        "solvent": "MeCN"
      }
    }
  ],
  "quality": {
    "rag_eligible": true,
    "chunk_count": 1
  }
}
```

## Task Datasets 与 Annotation Patches

exporter 可以派生：

- `ChemdTrainingTaskDatasetV1`
- `ChemdTrainingCampaignV1`
- `ChemdTrainingCampaignTaskDatasetV1`
- `ChemdTrainingAnnotationPatchV1`

这些输出支持 SFT/eval examples、跨文档 strategy examples，以及 reaction taxonomy、expert routing、optimization trajectories、failure signals、intent hypotheses、variable logic、causal links、material-flow edges、step dependencies 和 task examples 的人工修正。
